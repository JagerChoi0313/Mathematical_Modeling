
Q3_Desert_MultiPlayer
=====================

运行方法
--------
1. 保持当前文件夹结构不变。
2. MATLAB 当前文件夹切换到本项目根目录。
3. 运行 main.m。
4. 第五关需要 Optimization Toolbox（intlinprog）。
5. 第六关为纯 MATLAB 动态规划与联合动作枚举，不需要额外优化工具箱。

模型口径
--------
第五关：
- n=2。
- 天气全部已知，采用两玩家时空网络 MILP。
- 目标为最大化两名玩家最终资金之和。
- 同一有向边同日两人同行时，每人移动消耗倍率为 4。
- 同一矿山同日两人挖矿时，每人消耗倍率为 3，每人收益为基础收益的 1/2。

第六关：
- n=3。
- 延续第二问第四关的量化假设：30天内沙暴不超过3天。
- 晴朗在最坏情形下严格优于高温，因此保证值只比较高温和沙暴。
- 为控制三玩家联合状态规模，先计算单玩家保证价值函数，再逐日枚举三玩家联合动作，
  当天的多人相互作用按题目规则精确计算。
- 初始采购先搜索共同方案，再逐玩家直接枚举改进一次。

输出目录
--------
