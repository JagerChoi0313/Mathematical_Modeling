# 第四问 MATLAB 程序：精确二项置信域与装配树鲁棒枚举

## 1. 运行

三个 `.m` 文件放在同一文件夹，以 UTF-8 保存。MATLAB 当前文件夹切换到此处：

```matlab
R = Q4_robust_main;
```

面向 MATLAB R2020a 及以上；不依赖统计、优化或并行计算工具箱。置信限使用基础 MATLAB 的 `betaincinv`，不是工具箱函数 `betainv`。

**没有提供真实抽样记录时，默认运行的是模拟示例。** 每种次品率预设样本量200，用题目名义率生成二项抽样计数，随机种子20240908。200是示例设计值，不是题目给定值；模拟计数不等于实测数据。本程序在运行结束后恢复原随机数状态。

三个代码文件各司其职：

| 文件 | 内容 |
| --- | --- |
| Q4_robust_main.m | 模拟/读取抽样计数、精确置信区间、全策略枚举、最优比较和回归核验 |
| Q4_tree_evaluate.m | 批量评价装配树固定策略，单策略事件次数和成本分解 |
| Q4_export_results.m | 中文 Excel、七幅中文图、PNG/PDF/FIG、MAT与报告 |

## 2. 输入真实抽样数据

输入的是**样本量和整数次品数**，不是仅有百分比的次品率。

| 字段 | 尺寸 | 顺序 |
| --- | --- | --- |
| samples.Q2_n | 6×3 | 行为第二问情形1~6；列为零件1、零件2、成品 |
| samples.Q2_x | 6×3 | 与Q2_n逐格对应的次品数 |
| samples.Q3_n | 12×1 | 零件1~8、半成品1~3、成品 |
| samples.Q3_x | 12×1 | 与Q3_n逐行对应的次品数 |

所有样本量为正整数；每个次品数是0到对应样本量之间的整数。半成品和成品的样本必须在**直接投入物全部合格**的条件下取得，否则估计的不是本模型所需的条件装配次品率。

可将自己的Excel工作簿设置为下列两个工作表，首行为中文或英文表头：

- `Q2抽样`：A:G为情形编号、n1、x1、n2、x2、n成品、x成品；数据范围A2:G7。
- `Q3抽样`：A:C为节点编号、n、x；数据范围A2:C13。

读取示例（将文件名改成自己的实际路径）：

```matlab
A = readmatrix('我的真实抽样记录.xlsx', 'Sheet','Q2抽样', 'Range','A2:G7');
B = readmatrix('我的真实抽样记录.xlsx', 'Sheet','Q3抽样', 'Range','A2:C13');
assert(isequal(A(:,1),(1:6)') && isequal(B(:,1),(1:12)'), '编号顺序错误');
samples.Q2_n = A(:,[2 4 6]);
samples.Q2_x = A(:,[3 5 7]);
samples.Q3_n = B(:,2);
samples.Q3_x = B(:,3);
R = Q4_robust_main(samples);
```

也可以在MATLAB中直接为这四个数组赋值。没有真实数据时，不要把示例数组改名为“实测”。条件次品率取样的投入物检测信息也应保留在自己的原始记录中。

## 3. 常用选项

```matlab
opts = struct();
opts.alpha = 0.05;
opts.confidenceFamily = 'perProblem';
opts.fontName = 'Microsoft YaHei'; % 若系统安装了其他中文字体，填实际名称
opts.figureVisible = 'on';
opts.confidenceLevels = [0.90 0.95 0.99];
R = Q4_robust_main([],opts);       % []仍表示模拟数据模式
```

`confidenceFamily='perProblem'`：第二问每个情形分别对3个参数建立联合至少95%覆盖的置信域；第三问对12个参数建立联合至少95%覆盖的置信域。**不是30个参数整体同时95%。**

`confidenceFamily='all30'`：对第二问18个率和第三问12个率作为一个30参数家族分配alpha，整体同时覆盖至少95%。Bonferroni不要求各组估计彼此独立，但每一组固定样本量二项模型仍须成立。

```matlab
% 仅计算，不绘图、不写文件：
R = Q4_robust_main([], struct('makeFigures',false,'saveFiles',false));

% 改变模拟示例的设计样本量；真实输入模式中此选项不改变用户数据：
R = Q4_robust_main([], struct('exampleSampleSize',500,'randomSeed',20240908));

% 为所有30个参数统一控制联合覆盖：
R = Q4_robust_main(samples, struct('confidenceFamily','all30'));
```

其他选项：`checkVertices=true`、`tieTolerance=1e-8`、`outputRoot`为输出总文件夹。主程序遇到拼错的选项会报错，避免静默忽略。

## 4. 模型和算法对应

1. 对固定、预先确定的样本量n和次品数x，计算点估计x/n。
2. 对一个含K个参数的置信家族，每个参数分配显著性水平alpha/K，建立双侧Clopper–Pearson精确区间。
3. 第二问枚举16个四位策略。第三问原始16位编码65536种，半成品不检测时拆解位不触发，合并为27648个候选；去重不等于筛除不可行策略。
4. 对每个候选，在点估计向量和全部置信上界向量分别进行装配树递推。点估计可行性与鲁棒可行性分别判定。
5. 最大化点估计利润得到点估计最优；最大化最坏情形利润得到鲁棒最优。两类最优均保留全部并列策略。
6. 核对第二问全部8个置信域顶点，以及若干置信域内部参数点；回归检验原第二问六种情形和第三问的名义参数结果。
7. 对代表方案分解期望事件次数和成本，核验“事件次数×单价=总成本”，输出图表。

### 为什么可以只评价置信上界

限定本程序的固定策略规则后，有限成本策略的成本对每个次品率都单调不减：叶节点检测供给成本为`(采购费+检测费)/(1-p)`；不检测半成品的成本为投入成本加装配费；报废重来分支的成功概率下降会提高期望重做费用；拆解复用分支仅在直接投入物必然合格时有限，其重复装配成本也随本层次品率提高而增加。沿树自底向上即可归纳得到根节点单调性。

因此，长方体置信域内每个固定策略的最大期望成本在全部上界处取得。无法完成交付的策略用无限成本表示。第二问顶点核验只是数值一致性检查，**不是没有单调性等前提时，枚举顶点也能精确求解任意非线性鲁棒模型**。

### 递推规则保持不变

- 质量判定无误检/漏检，检测出的不合格零件丢弃并重新购买；已知合格物料不复检。
- 半成品不检测时，一次装配后向上提供，本层拆解位忽略。
- 不合格品报废时，重新取得整套直接投入物。
- 拆解仅回收原来的直接投入物，不修复其质量；本程序不新增失败后的自适应检测或深层拆解。
- 直接投入物可能不合格却永久复用时，有正概率永久循环；由于持续产生正装配费，期望成本为无穷。
- 成品不检测仍可能被顾客退回，所以其拆解位不能合并。
- 一次订单仅有一次销售收入，直到合格交付；调换损失不含替换品生产成本，后者已由递推累加。
- 抽样费用尚未按订单分摊；需要额外的抽样收费规则和对应订单规模才能计算这一项。固定的同一笔抽样费不改变当前策略排序。

### 边界和统计解释

- x=0时置信下界为0，但上界大于0，不能把样本零次品当成确定无次品。
- x=n时置信上界为1。程序不截断这个1。如果置信域包含必要节点完全不能产出合格物料的情况，则不存在有限成本的鲁棒保证；这不是程序故障。
- `最坏情形利润`是置信域内的**期望利润下界**，不是每个实际订单必赚多少元，也不是参数的贝叶斯后验分位数。
- 固定样本量置信区间不能在随结果不断追加样本并反复检验时，无修正地继续宣称原联合覆盖率。
- 点估计与鲁棒最优相同只表示两个目标下选择一致，不能直接推出整个置信域内排名稳定。
- 本程序只优化既定固定策略集合，不宣称覆盖所有自适应返工政策。

## 5. 输出文件和主要变量

每次运行创建新的`Q4_results/run_日期_时间/`，不覆盖旧结果。

- `Q4_tables.xlsx`：使用说明、30组抽样计数与置信区间、7个问题的汇总、全部候选、全部并列最优、成本/操作次数/节点递推、原题参数、编码说明和核验。全部程序table均导出。
- `Q4_results.mat`：完整结构体R，可用于复算和重新绘图。
- `Q4_report.txt`：数据来源、关键最优结果和保证范围。
- 7张图，每张保存300dpi PNG、矢量PDF和可编辑FIG。

图1为精确置信区间，图2为两类方案利润比较，图3为第二问鲁棒利润热图，图4为第三问点估计/最坏利润散点图，图5为决策对照，图6为鲁棒成本分解，图7为同一份样本下90%/95%/99%置信水平对比。每张图均标注样本来源。

常用结果：

```matlab
R.tables.summary                      % 七个问题的关键对比
R.tables.samples                      % 样本计数、点估计、置信上下界
R.problems{1}.tables.robustOptimal     % 第二问情形1的全部鲁棒最优
R.problems{7}.tables.robustOptimal     % 第三问的全部鲁棒最优
R.problems{7}.tables.allStrategies     % 第三问27648个候选
R.tables.costs                        % 代表方案的两种参数情景成本
R.tables.checks                       % 数值核验
R.regression                          % 原第二、三问名义参数的回归结果
```

`PointOwnProfit`为点估计最优方案在样本次品率下的利润；`PointWorstProfit`为同一方案在置信域内的利润下界；`RobustPointProfit`为鲁棒方案在样本次品率下的利润；`RobustWorstProfit`为鲁棒最优方案的利润下界。代表方案均按最小编号选取，点估计并列最优不偷偷增加第二层最坏利润优化。

`WorstGain=RobustWorstProfit-PointWorstProfit`比较两个代表方案的最坏利润。若点估计方案鲁棒不可行而鲁棒方案可行，这一改善量为Inf，只能解释为从“无有限保证”转为“有有限保证”，不是获得了无限元收益。Excel中的NaN与Inf用明确文字展示；未定义情形不填0。
