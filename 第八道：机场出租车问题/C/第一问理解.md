# 一、先把整道题“翻译成人话”

这道题研究的是：**出租车把乘客送到机场以后，接下来应该怎么做，机场管理部门又应该怎样组织出租车载客。**

出租车司机送客到机场后，有两个选择：

- **选择A：留在机场排队。**
  进入蓄车池等待，轮到自己后再从机场载客回市区。优点是通常能够获得一笔机场到市区的载客收入；缺点是可能排队很久。
- **选择B：空车返回市区。**
  不在机场等待，直接空载回市区重新寻找乘客。优点是不用排队；缺点是要承担空驶成本，并且可能错过机场乘客。

所以，这道题的本质不是单纯研究“出租车怎么排队”，而是研究三个相互关联的问题：

1. **司机个人怎么选择，才能让自己的预期收益更高；**
2. **机场怎么组织车辆和乘客，才能提高上车效率；**
3. **机场怎么制定优先规则，才能让长途和短途司机的收益更加公平。**

------

# 二、这道题研究的对象是什么

整道题有四类主要研究对象。

## 1. 出租车司机

司机关心的是自己的收益，包括：

- 能获得多少车费；
- 要等待多长时间；
- 空车行驶需要多少成本；
- 等待期间可能损失多少市区载客收入；
- 排队后能不能顺利载到乘客。

## 2. 机场到达乘客

并不是所有下飞机的乘客都会坐出租车，因此要研究：

- 某个时间段到达多少架航班；
- 每架航班有多少乘客；
- 有多少乘客选择出租车；
- 乘客下飞机后多久到达出租车乘车区；
- 乘客数量随时间怎样变化。

## 3. 机场出租车排队系统

包括两个队列：

- 蓄车池中的出租车队列；
- 乘车区中的乘客队列。

出租车和乘客必须进行匹配，所以这是一个典型的**双边排队与服务系统**。

## 4. 机场管理部门

管理部门需要决定：

- 出租车每次放行多少辆；
- 乘车区设置几个上车点；
- 上车点如何布局；
- 哪些短途返回车辆可以优先；
- 如何兼顾效率、安全和公平。

------

# 三、四个问题分别要解决什么

## 问题一：司机应该排队，还是直接返回市区

### 要解决的内容

建立一个司机选择模型，比较以下两种方案的收益：

- 留在机场排队载客；
- 空车返回市区寻找乘客。

最终需要给出类似下面的决策规则：

> 当蓄车池车辆较少、预计乘客较多、预计等待时间较短时，选择机场排队；
> 当蓄车池车辆较多、预计乘客较少、等待时间较长时，选择空车返回市区。

### 问题类型

问题一主要属于：

> **不确定条件下的决策优化问题**

同时还包含：

- 乘客数量的预测；
- 排队等待时间估计；
- 出租车收益建模；
- 阈值决策。

它不是单纯的预测题，也不是评价题。预测乘客数量和等待时间只是中间步骤，最后目的是帮助司机作出选择。

------

## 问题二：针对具体机场给出实际选择方案

### 要解决的内容

问题一建立的是一般模型，问题二要求选择一个真实机场，例如：

- 北京首都机场；
- 上海浦东机场；
- 广州白云机场；
- 成都天府机场；
- 长沙黄花机场。

然后收集该机场及所在城市的数据，包括：

- 不同时段到达航班数量；
- 航班载客量；
- 出租车蓄车池车辆数量；
- 机场到市区距离；
- 出租车收费标准；
- 出租车油耗或电耗；
- 市区出租车单位时间收入；
- 机场大巴、地铁运营时间等。

把真实数据代入问题一模型，得到具体策略。例如：

> 在18:00—21:00，当蓄车池车辆少于某一数量时建议排队；超过该数量时建议空车返回。

还要改变一些因素的数值，看结果是否发生变化，从而进行敏感性分析。

### 问题类型

问题二属于：

> **实证分析与模型验证问题**

其中还包括：

- 数据统计分析；
- 参数估计；
- 模型求解；
- 敏感性分析；
- 模型合理性检验。

------

## 问题三：怎样设置两条车道的上车点

### 要解决的内容

机场乘车区有两条并行车道，需要决定：

- 设置多少个上车点；
- 上车点设置在哪里；
- 两条车道如何分工；
- 出租车以什么顺序进入；
- 乘客如何排队；
- 每批放行多少出租车；
- 如何避免前车阻挡后车；
- 如何兼顾效率和安全。

最终目标是让单位时间完成上车的乘客数量最大，或者让车辆平均停留时间最短。

### 问题类型

问题三主要属于：

> **布局优化与调度优化问题**

通常会结合：

- 排队论；
- 离散事件仿真；
- 车辆调度模型；
- 服务台配置模型；
- 整数规划或枚举优化。

它不是普通的几何建模。虽然涉及位置和布局，但最终衡量的是整个系统的运行效率。

------

## 问题四：怎样给短途返回出租车优先权

### 要解决的内容

机场出租车不能挑选乘客，因此有的司机载到长途乘客，收入很高；有的司机载到短途乘客，收入较低。

如果短途司机再次返回机场后仍然从队尾排队，就会产生明显的不公平。因此需要制定一个优先规则，例如：

- 短途司机返回后进入优先通道；
- 减少一定的排队车辆数；
- 按照短途里程给予不同优先等级；
- 规定优先权的有效时间；
- 限制连续优先次数，防止制度被滥用。

目标不是简单让短途司机“插队”，而是在不严重降低整体效率的条件下，使司机长期平均收益更加均衡。

### 问题类型

问题四主要属于：

> **公平性约束下的优先调度优化问题**

可以涉及：

- 多目标优化；
- 优先级排队模型；
- 收益均衡模型；
- 公平性评价；
- 规则设计与仿真检验。

------

# 四、四问之间是什么关系

这四问不是四个互不相关的小题，而是一条逐步深入的研究路线。

| 问题   | 研究角度     | 核心目标                   |
| ------ | ------------ | -------------------------- |
| 问题一 | 单个司机     | 决定排队还是返回市区       |
| 问题二 | 真实机场     | 用实际数据得到具体决策方案 |
| 问题三 | 机场乘车区   | 提高车辆与乘客匹配效率     |
| 问题四 | 机场管理规则 | 平衡长途、短途司机收益     |

因此可以理解为：

> 第一问研究司机怎么选，第二问用真实数据验证，第三问研究机场怎么提高效率，第四问研究机场怎么兼顾公平。

------

# 五、重点理解问题一

## 1. 问题一到底让我们干什么

问题一要求完成三件事。

### 第一件事：找出影响司机决策的因素

司机选择排队还是返回，主要取决于两种方案的预期收益。

影响“机场排队方案”的因素包括：

- 蓄车池中已有出租车数量；
- 未来一段时间到达的航班数量；
- 每架航班的乘客人数；
- 乘客选择出租车的比例；
- 预计排队等待时间；
- 机场到乘客目的地的平均距离；
- 机场出租车平均车费；
- 等待期间的时间成本。

影响“空车返回方案”的因素包括：

- 机场到市区的空驶距离；
- 油费、电费和过路费；
- 空车返回时间；
- 返回市区后找到乘客的概率；
- 市区单位时间平均收入；
- 市区巡游等待时间；
- 司机在机场排队可能获得的收益。

------

## 2. 什么叫“分析影响机理”

题目不只是让我们把因素列出来，还要说明它们如何影响最终决策。

例如：

### 蓄车池车辆数增加

车辆越多，司机排在越后面，预计等待时间越长，选择机场排队的吸引力越低。

关系可以表示为：

[
N_q\uparrow \Rightarrow T_w\uparrow \Rightarrow R_A\downarrow
]

其中：

- (N_q) 表示蓄车池排队车辆数；
- (T_w) 表示预计等待时间；
- (R_A) 表示选择机场排队的预期收益。

### 到达航班数量增加

航班越多，潜在乘客越多，出租车队列消化速度越快，等待时间通常越短，因此更适合排队。

[
F\uparrow \Rightarrow \lambda_p\uparrow
\Rightarrow T_w\downarrow
\Rightarrow R_A\uparrow
]

其中：

- (F) 表示到达航班数量；
- (\lambda_p) 表示选择出租车的乘客到达率。

### 市区出租车收入增加

如果市区正值用车高峰，司机空车返回后更容易接单，那么返回市区的机会收益会增加，司机更可能选择直接离开机场。

[
r_c\uparrow \Rightarrow R_B\uparrow
]

其中 (R_B) 表示空车返回市区的预期收益。

这就是“影响机理”：不是只说“航班数量会影响决策”，而是要把中间的作用过程说明白。

------

# 六、问题一最核心的建模思想

问题一最适合采用：

> **两种方案的预期净收益比较模型**

司机分别计算两种选择的预期净收益。

## 1. 机场排队方案

可以将排队方案的预期净收益写成：

[
U_A=E(I_A)-C_A-C_w
]

其中：

- (E(I_A))：从机场载客返回的预期收入；
- (C_A)：载客行驶产生的油费、电费、过路费等；
- (C_w)：排队等待的时间成本。

若等待时间为 (T_w)，司机单位时间的机会成本为 (v_t)，则：

[
C_w=v_tT_w
]

所以：

[
U_A=E(I_A)-C_A-v_tT_w
]

------

## 2. 空车返回市区方案

可以写成：

[
U_B=E(I_B)-C_0-C_s
]

其中：

- (E(I_B))：返回市区后能够获得的预期载客收益；
- (C_0)：从机场空车返回市区的直接成本；
- (C_s)：返回市区和寻找乘客过程中的时间成本。

------

## 3. 最终决策规则

比较两种方案：

[
\Delta U=U_A-U_B
]

如果：

[
\Delta U\geq 0
]

说明机场排队的预期收益不低于空车返回，应选择机场排队。

如果：

[
\Delta U<0
]

则选择直接返回市区。

因此，第一问最后应当得到的不是一个固定答案，而是一个**随时间和现场情况变化的动态选择规则**。

------

# 七、第一问真正困难的地方在哪里

第一问并不难在收益公式，而是难在下面三个中间量。

## 1. 怎样估计机场出租车乘客数量

到达机场的人数不等于出租车乘客数量。

可以建立：

[
Q(t)=\sum_{i=1}^{n(t)}
S_i\alpha_i\beta_i\gamma_i
]

其中：

- (n(t))：某时间段内到达的航班数；
- (S_i)：第 (i) 架航班的座位数；
- (\alpha_i)：客座率；
- (\beta_i)：到达旅客比例，排除中转等旅客；
- (\gamma_i)：乘坐出租车的比例。

此外，航班落地后，乘客不会马上到达出租车乘车区，还要经历：

- 下飞机；
- 行李提取；
- 安检或边检；
- 步行到乘车区。

因此要设置一个时间延迟。

------

## 2. 怎样估计排队等待时间

最简单的理解是：

> 自己前面有多少辆出租车 ÷ 单位时间能够消化多少辆出租车。

假设：

- 蓄车池中已有 (N_q) 辆出租车；
- 单位时间到达乘车区的出租车乘客组数为 (\lambda_t)。

那么可近似表示为：

[
T_w\approx\frac{N_q}{\lambda_t}
]

但这只是基础近似。实际还要考虑：

- 乘客到达率随时间变化；
- 航班可能集中到达；
- 机场分批放行出租车；
- 一组乘客可能包含多人；
- 一辆出租车通常服务一组同行乘客；
- 可能出现出租车队列先清空或乘客队列先清空。

因此，第一问可以使用简单排队关系，也可以使用基于时间段的动态供需平衡模型。

------

## 3. 怎样计算“时间成本”

时间成本不能简单地认为“等待一小时损失固定工资”。

更合理的定义是：

> 如果司机没有在机场排队，这段时间在市区可能获得的预期净收益。

例如司机在市区平均每小时净收入为 (r)，则等待 (T_w) 小时的机会成本可表示为：

[
C_w=rT_w
]

这种处理比主观赋权更加自然，因为它直接与司机实际收益有关。

------

# 八、问题一属于哪一种数学建模题

从主要目标看，问题一属于：

## 主要类型

[
\boxed{\text{决策优化问题}}
]

因为最终要在两个方案中选择收益更高的方案。

## 辅助类型

同时包含：

[
\boxed{\text{预测}+\text{排队分析}+\text{收益拟合}}
]

具体来说：

- 预测乘客数量；
- 估计出租车排队时间；
- 建立收益与等待时间、距离等因素的关系；
- 通过收益比较进行决策。

它不属于分类问题，因为不是先给大量“排队/返回”的历史标签，再训练分类器；也不属于普通评价问题，因为两个方案有明确的经济收益，可以直接比较，不需要人为设置大量评价指标和权重。

------

# 九、问题一建议的完整思维链

后续真正建模时，可以按下面六步进行。

### 步骤一：划分时间段

例如按照每30分钟或每1小时划分机场运行时间。

### 步骤二：预测出租车乘客到达量

根据到达航班、客座率和出租车选择比例，得到各时间段乘客数量。

### 步骤三：估计排队等待时间

利用蓄车池车辆数和乘客到达速度，估计司机需要等待多久。

### 步骤四：计算排队方案收益

考虑：

- 机场载客收入；
- 行驶成本；
- 等待时间成本。

### 步骤五：计算空车返回收益

考虑：

- 空驶费用；
- 返回时间；
- 市区接单概率；
- 市区预期收入。

### 步骤六：比较收益并得到决策阈值

得到类似以下规则：

[
N_q\leq N^*(t)
]

时选择排队，否则返回市区。

这里的 (N^*(t)) 是不同时间段允许排队的最大车辆数，也可以理解为司机决策的临界值。

# 十、第一问最后应该得到什么结果

一份完整的第一问结果通常包括四部分。

## 1. 影响因素关系图

说明：

- 航班数量如何影响乘客到达量；
- 乘客数量和排队车辆数如何影响等待时间；
- 等待时间如何影响司机收益；
- 最终如何影响司机决策。

## 2. 两种方案的收益函数

分别给出：

[
U_A
]

和

[
U_B
]

的表达式。

## 3. 决策规则

例如：

[
U_A\geq U_B
\Rightarrow \text{排队}
]

[
U_A<U_B
\Rightarrow \text{返回市区}
]

## 4. 临界条件或策略表

例如：

| 机场状态               | 建议选择         |
| ---------------------- | ---------------- |
| 航班较多、车辆较少     | 进入蓄车池排队   |
| 航班较少、车辆较多     | 空车返回市区     |
| 市区处于早晚高峰       | 更倾向于返回市区 |
| 夜间市区接单困难       | 更倾向于机场排队 |
| 预计等待时间低于临界值 | 排队             |
| 预计等待时间高于临界值 | 返回市区         |

------

# 十一、这一题最容易出现的误区

第一，不要一上来就使用层次分析法、熵权法或TOPSIS。司机真正关心的是预期净收益，两种方案可以直接用货币和时间成本进行比较，没有必要人为打分。

第二，不要只比较“机场车费”和“空驶油费”。排队损失的时间可能比油费更重要，必须考虑机会成本。

第三，不要直接用“到达航班数”代替出租车乘客数。一架大型客机和一架小型客机的乘客数不同，而且不是所有乘客都会坐出租车。

第四，不要把乘客看成航班落地后立即出现。需要考虑下机、取行李和步行产生的时间延迟。

第五，不要把结果写成“司机应该排队”。正确结论应该是带条件的，例如“当预计等待时间小于某个临界时间时排队”。

------
