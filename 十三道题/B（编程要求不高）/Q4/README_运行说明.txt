第四问 MATLAB 代码包运行说明
========================================

一、代码功能
----------------------------------------
主程序 Q4_experiment_design_main.m 根据论文第四问建立的
“包含第三问最优点约束的增广D最优—空间填充混合实验设计模型”，
从已有114条实验数据出发，选择5组新增实验方案。

程序完成以下工作：
1. 读取第二问的响应面系数、标准化参数和解析后的原实验数据；
2. 构造包含主效应、平方项和两两交互项的17列完整二次设计矩阵；
3. 强制加入第三问预测最优点；
4. 通过五水平分层设计，使每个因素在5次实验中覆盖不同区间；
5. 删除响应面预测不符合0%~100%物理范围的设计；
6. 设置新增点之间、探索点与原实验点之间的最小距离；
7. 在可行设计中选择增广信息矩阵log(det)最大的方案；
8. 输出Excel结果和4张论文图片。


二、运行环境
----------------------------------------
建议使用 MATLAB R2020b 或更高版本。

程序只使用MATLAB基础功能，不需要：
- Optimization Toolbox
- Statistics and Machine Learning Toolbox

程序需要能够读取和写入 .xlsx 文件。


三、输入文件
----------------------------------------
代码包中已经包含：

Q2_response_surface_results.xlsx

它是第二问程序生成的结果文件。主程序至少需要其中4个工作表：

1. ParsedData
   必需列：
   CoLoading_wtPct
   CoSiO2_Fraction
   TotalCatalyst_mg
   Ethanol_mlMin
   Temperature_C
   LoadingMethod_D

2. Standardization
   必需列：Factor、Mean、Std、Min、Max
   前4行依次对应Co负载量、装料比例、乙醇浓度和温度。

3. Conv_Coefficients
   必需列：Term、Coefficient
   保存乙醇转化率响应面模型的项名称和系数。

4. C4_Coefficients
   必需列：Term、Coefficient
   保存C4烯烃选择性响应面模型的项名称和系数。

如果以后重新运行第二问，只需要用新的同名结果文件替换代码包中的Excel文件。


四、运行方法
----------------------------------------
1. 解压整个压缩包，不要只单独打开 .m 文件。
2. 启动MATLAB。
3. 将MATLAB“当前文件夹”切换到解压后的文件夹。
4. 打开 Q4_experiment_design_main.m。
5. 点击编辑器上方的“运行”，或者在命令行输入：

   Q4_experiment_design_main

6. 等待程序完成13824组分层设计的枚举和筛选。

程序会在当前文件夹中自动建立：

Q4_output
    Q4_experiment_design_results.xlsx
    figures
        Fig1_实验点空间分布.png
        Fig2_新增实验预测结果.png
        Fig3_设计矩阵奇异值比较.png
        Fig4_新增实验因素水平热图.png


五、Excel输出说明
----------------------------------------
Q4_experiment_design_results.xlsx包含两个工作表。

1. Five_Experiments
   给出5组新增实验的具体条件，包括：
   - Co负载量；
   - Co/SiO2占比；
   - Co/SiO2与HAP的实际质量；
   - 乙醇浓度；
   - 反应温度；
   - 装料方式和总装料量；
   - 预测乙醇转化率；
   - 预测C4烯烃选择性；
   - 预测C4烯烃收率；
   - 每个实验点带来的D准则信息增量。

2. Design_Diagnostics
   给出新增实验前后的设计矩阵秩、log(det)、最小空间距离以及
   候选设计数量等诊断指标。

七、如何解释运行结果
----------------------------------------
1. 实验1的作用
   实验1是第三问的预测最优方案。它的主要任务是验证模型预测的
   51.551%高收率能否在真实实验中实现。该点位于低乙醇浓度和高温边界，
   因此必须进行实际实验验证，不能把预测值直接当成真实结果。

2. 实验2~5的作用
   这4组实验主要用于补充原实验空间和提高模型精度，不以收率最大为目标。
   因此其中部分方案的预测收率可能较低，这并不说明实验设计失败。
   低收率区域同样可以帮助判断响应面边界、识别因素交互作用并防止模型外推错误。

3. 设计矩阵秩的含义
   当前原始完整二次设计矩阵的秩应为15，而完整模型共有17列。
   说明原实验无法独立识别全部高阶项。加入5个新实验后，矩阵秩应提高到17，
   表明原来混叠的交互项可以被进一步区分，模型参数估计条件得到改善。

4. log(det)的含义
   log(det)越大，表示增广后的实验设计总体信息量越大，回归参数联合置信区域越小。
   该指标主要用于不同五点设计之间的相对比较，不应解释为C4收率。

5. 距离指标的含义
   新增点最小两两距离反映5个实验点之间的分散程度；
   探索点到原实验的最小距离反映新实验对原样本空白区域的补充程度。
   两者越大，一般说明空间覆盖越充分。


八、实验操作注意事项
----------------------------------------
问题一表明乙醇转化率会随反应时间显著下降。因此实际进行这5次实验时，
必须统一催化剂使用状态和取样时间。建议每组使用新制备催化剂，或者严格规定
从通入乙醇开始到检测的时间，否则时间效应可能掩盖催化剂组合和温度效应。

当Co/SiO2占比为1时，HAP质量为0。若实验装置需要使用惰性石英砂维持床层，
应保持石英砂加入规则在相应对照实验中一致，并在论文中明确说明。


九、常见报错
----------------------------------------
1. “未找到第二问结果文件”
   请确认Excel文件和主程序在同一文件夹中，并且文件名以
   Q2_response_surface_results开头。

2. “ParsedData工作表缺少必要列”
   请使用第二问Q2_main_v3程序生成的完整结果文件，不要使用手工删减后的表格。

3. 图片中文字显示为方框
   这是电脑缺少中文字体造成的，不影响计算结果。可在MATLAB字体设置中选择
   微软雅黑、宋体或黑体。

4. 程序运行时间较长
   程序需要比较13824组候选五点设计。普通电脑一般可以完成，请等待命令窗口
   出现“程序运行完成”。
