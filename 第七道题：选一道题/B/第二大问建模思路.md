下面我们开始看**第二问**。第二问原题是：

> 为附件一中的项目设计新的任务定价方案，并和原方案进行比较。

这句话看起来短，但它是整道题的核心之一，因为它要在第一问分析原因的基础上，真正提出一个**改进定价方案**。

------

# 一、题目背景和研究对象

这道题的背景仍然是“拍照赚钱”类众包平台。平台发布任务，会员领取任务并完成拍照检查，平台给会员支付任务报酬。

第一问已经分析出：

原始定价与任务位置、会员分布、任务密度等因素有一定关系，但规律不强；部分任务没有完成，并不完全是因为位置偏远或附近会员少，而是与任务密集区域中的竞争关系、价格吸引力不足有关。

所以第二问的研究对象是：

> **附件一中已经结束的 835 个任务。**

也就是说，第二问不是给附件三的新项目定价，而是对附件一原来的任务重新设计价格。

附件一中的每个任务都有：

- 原始任务价格；
- 经纬度位置；
- 实际完成情况；
- 周边会员信息可以通过附件二计算得到。

第二问要做的是：

> 在附件一原始任务的基础上，重新设计一套更合理的任务价格，并判断这套新价格是否优于原来的价格。

------

# 二、第二问到底要解决什么问题？

第二问不是简单地“把没完成的任务价格调高”，而是要解决一个更完整的问题：

> 如何在控制平台总成本的前提下，提高任务完成率？

如果所有任务都大幅涨价，完成率可能提高，但平台成本也会增加，这不是一个好的方案。

所以第二问需要同时考虑两个目标：

第一，**提高任务完成率**。

第二，**控制任务总成本**。

因此，第二问的核心矛盾是：

> 价格太低，任务可能没人做；价格太高，平台成本过高。

这就是第二问最重要的建模思想。

------

# 三、第二问可以拆成几个小任务理解

## 1. 根据第一问结果，判断哪些任务需要调价

第一问已经得到一些重要结论：

未完成任务的平均价格低于完成任务；

未完成任务多出现在任务和会员较密集区域；

未完成任务的单位竞争价格较低；

原定价没有充分考虑局部任务竞争关系。

所以第二问第一步应该是：

> 判断哪些任务原价格不合理，哪些任务需要提高价格，哪些任务可以保持不变。

这一步属于：

> **数据分析 / 评价问题**

因为它是在评价原价格是否合理。

------

## 2. 构造新的任务定价规则

第二问最核心的部分是设计新价格。

新价格不能凭感觉给，而应该根据第一问的影响因素来调整。

新定价应考虑：

- 原始价格；
- 最近会员距离；
- 周边会员数量；
- 任务密度；
- 竞争强度；
- 单位竞争价格；
- 任务预测完成概率。

例如：

如果某任务预测完成概率低，就适当提高价格；

如果某任务周边任务密度高、竞争强，就增加竞争补偿；

如果某任务原价格已经较高且预测完成概率较高，就不需要明显涨价。

这一步属于：

> **优化问题 / 定价模型问题**

因为我们要确定每个任务的新价格，使方案整体更优。

------

## 3. 用第一问的 Logistic 模型预测新方案效果

第二问设计新价格后，要判断新方案好不好。

但附件一已经结束了，不能真的重新执行一次，所以只能用模型预测：

> 如果按照新价格发布，这些任务的完成概率会不会提高？

这里可以继续使用第一问建立的 Logistic 回归模型。

把新价格代入模型，重新计算每个任务的新完成概率。

这一步属于：

> **预测问题**

因为它是在预测新定价方案下任务被完成的可能性。

------

## 4. 与原方案进行比较

第二问最后必须回答：

> 新方案和原方案相比，到底好在哪里？

比较时不能只说“价格更合理”，要给出具体指标。

可以比较：

| 比较指标           | 含义                           |
| ------------------ | ------------------------------ |
| 总任务成本         | 新方案总价格与原方案总价格对比 |
| 平均任务价格       | 新方案平均价格是否明显提高     |
| 预测完成率         | 新价格下任务预计完成比例       |
| 低完成概率任务数量 | 新方案是否减少难完成任务       |
| 单位成本提升效果   | 多花的钱是否带来了更高完成率   |

所以这一部分属于：

> **评价问题 / 方案比较问题**

------

# 四、第二问属于什么类型的问题？

第二问不是单纯一种问题，而是由几个问题组合成的。

| 环节                   | 问题类型     |
| ---------------------- | ------------ |
| 判断原价格是否合理     | 评价问题     |
| 根据任务特征重新定价   | 优化问题     |
| 预测新价格下的完成概率 | 预测问题     |
| 比较新旧方案           | 综合评价问题 |

所以第二问整体可以归纳为：

> **基于完成概率预测的任务定价优化与方案评价问题。**

其中最核心的是：

> **优化问题。**

因为第二问最终要输出一套新的任务定价方案。

Logistic 回归在第二问里不是主模型，而是作为评价新定价方案的工具：

> 第一问用 Logistic 回归分析未完成原因；
>  第二问用 Logistic 回归预测新价格下的任务完成概率。

------

# 五、第二问不属于什么问题？

第二问一般不属于：

## 1. 不属于分类问题

虽然会用到 Logistic 回归判断任务完成概率，但第二问的目标不是简单判断任务是完成还是未完成，而是要**设计价格**。

所以分类只是辅助。

------

## 2. 不属于拟合问题

第一问有拟合原定价规律的成分，第二问不是去拟合旧价格，而是设计新价格。

所以它不是主要的拟合问题。

------

## 3. 不属于几何建模问题

虽然会用到经纬度距离、任务密度等空间指标，但几何关系只是辅助特征，核心不是求几何位置或路径。

所以它不是几何建模问题。

------

# 六、第二问的核心建模思路

第二问可以这样理解：

> 先根据第一问模型计算每个任务的完成概率，再对低完成概率任务进行价格补偿，使任务完成概率提高，同时控制总成本，最后与原价格方案比较。

更具体地说：

**第一步：保留第一问构造的任务特征。**
 包括最近会员距离、周边会员数量、平均信誉值、平均预订限额、任务密度、竞争强度、单位竞争价格等。

**第二步：利用第一问 Logistic 模型计算原价格下的完成概率。**

**第三步：根据任务完成概率和任务竞争情况设计调价规则。**

**第四步：得到每个任务的新价格。**

**第五步：将新价格重新代入 Logistic 模型，预测新方案下的完成概率。**

**第六步：比较原方案和新方案的总成本、平均价格、预测完成率等指标。**

------

# 七、这一问最推荐的模型类型

我建议第二问使用：

> **基于 Logistic 完成概率约束的任务定价优化模型。**

这个名称比较适合写进论文。

它的含义是：

- 用 Logistic 模型预测任务完成概率；
- 用价格调整提高低概率任务的完成可能性；
- 用总成本或价格涨幅约束控制平台支出；
- 最后评价新旧方案优劣。

也可以写成：

> **基于完成概率预测的任务定价优化模型。**

这个名字更简单，更适合大一数学建模论文。

# 八、第二问一句话总结

第二问要做的不是重新分析原因，而是：

> **根据第一问发现的任务未完成原因，设计一套新的任务价格，使任务完成概率提高，并通过成本和完成率指标与原方案进行比较。**

它的本质是：

> **优化 + 预测 + 评价问题，其中优化是核心。**



下面针对**第二问：为附件一中的项目设计新的任务定价方案，并和原方案进行比较**来判断适合使用什么数学模型。题目要求我们不是单纯分析原价格，而是要在附件一原有任务数据基础上，重新设计价格，并评价新方案是否优于原方案。

# 1. 提取题目关键词

第二问的关键词主要有：

| 关键词                       | 含义                               |
| ---------------------------- | ---------------------------------- |
| 附件一中的项目               | 已有历史任务数据，可利用第一问结果 |

# 2. 根据关键词判断问题类型

第二问不是单纯的预测问题，也不是简单的回归问题，而是一个综合问题。

它主要包含三层：

第一层是**定价优化问题**。

因为我们要为附件一中的每个任务重新确定价格，使任务更容易完成，同时不能让总成本过高。

第二层是**完成概率预测问题**。

因为附件一已经结束，新价格不能真实重新执行，只能利用第一问建立的 Logistic 回归模型，预测新价格下任务的完成概率。

第三层是**方案评价问题**。

因为题目要求“和原方案进行比较”，所以必须比较新旧方案的总成本、平均价格、预测完成率、低完成概率任务数量等指标。

因此，第二问整体属于：

> **基于完成概率预测的任务定价优化与方案评价问题。**

其中，最核心的是：

> **优化问题。**

------

# 3. 推荐 2 到 3 种可行模型

## 模型一：基于 Logistic 完成概率的定价优化模型

### 建模逻辑

第一问已经建立了 Logistic 回归模型，可以根据任务价格、最近会员距离、周边会员数量、任务密度、单位竞争价格等因素预测任务完成概率。

第二问可以把任务价格看作决策变量，通过调整任务价格，使每个任务的完成概率尽量达到某个目标水平。

基本思路是：

> 原始价格 → 预测原完成概率
>  调整价格 → 得到新价格
>  新价格代入 Logistic 模型 → 预测新完成概率
>  比较新旧方案完成率和成本

也就是说，新定价不是凭感觉，而是根据完成概率进行调价。

如果某任务原完成概率低，就适当提高价格；如果某任务原完成概率已经较高，则价格可以保持不变或少量调整。

### 优点

这个模型和第一问衔接最自然。

第一问用 Logistic 回归分析未完成原因，第二问继续用它预测新价格下的完成概率，逻辑连贯，论文好写。

### 缺点

它依赖第一问 Logistic 模型的预测效果。如果 Logistic 模型解释能力一般，那么新方案评价也只能作为预测评价，而不能代表真实执行结果。

------

## 模型二：多目标优化模型

### 建模逻辑

第二问本质上存在两个目标：

一方面，希望任务完成率尽可能高；

另一方面，希望平台总成本尽可能低。

因此可以建立多目标优化模型：

> 目标 1：最大化任务预测完成率；
>  目标 2：最小化任务总定价成本。

由于两个目标存在冲突，实际建模时可以把它转化为单目标模型。例如：

> 在总成本增加不超过一定比例的条件下，最大化预测完成率；

或者：

> 在预测完成率达到某一目标的条件下，最小化总成本。

### 优点

这个模型从“优化”的角度非常正规，符合数学建模竞赛风格。

### 缺点

对大一同学来说写起来稍微复杂，需要设置目标函数和约束条件。如果约束设置得不好，容易显得人为。

------

## 模型三：分层调价模型

### 建模逻辑

先根据第一问得到的任务特征，将任务分成不同类型，再对不同类型任务采用不同调价规则。

例如可以按照预测完成概率分层：

| 任务类型         | 调价策略           |
| ---------------- | ------------------ |
| 高完成概率任务   | 保持原价或小幅调整 |
| 中等完成概率任务 | 适度提高价格       |
| 低完成概率任务   | 明显提高价格       |

也可以结合任务密度和单位竞争价格分层：

| 任务情况                   | 调价思路       |
| -------------------------- | -------------- |
| 任务密度高且单位竞争价格低 | 增加竞争补偿   |
| 最近会员距离远             | 增加距离补偿   |
| 周边会员承接能力强         | 可减少涨价幅度 |
| 原完成概率较高             | 不必明显涨价   |

### 优点

这种模型容易理解，计算也不复杂，很适合论文展示。

### 缺点

它偏规则型，优化性不如严格的数学优化模型强。如果只用分层调价，论文可能显得数学味稍弱。

------

| Logistic 完成概率定价优化模型 | 根据完成概率反推新价格 | 与第一问衔接自然，解释性强 | 依赖第一问预测模型 |

# 第二问模型的建立

## 1. 问题分析

第一问已经建立了任务完成概率模型，并发现任务是否完成不仅与任务价格有关，还与最近会员距离、周边会员数量、平均预订限额、任务密度和单位竞争价格等因素有关。

第二问要求对附件一中的原任务重新设计价格。因此，本问的核心不是重新分析未完成原因，而是：

> 在控制平台成本的前提下，通过调整任务价格，提高任务的预测完成概率，并与原定价方案进行比较。

若简单提高所有任务价格，虽然可能提高完成率，但平台成本也会明显增加。因此，新定价方案应重点对预测完成概率较低、竞争压力较大、原价格吸引力不足的任务进行补偿，而对原本完成概率较高的任务保持价格稳定。

因此，本问属于：

> **基于完成概率预测的任务定价优化问题**。

其中，Logistic 回归模型用于预测任务完成概率，优化模型用于确定新的任务价格，评价指标用于比较新旧方案。

------

## 2. 模型假设

1. 任务位置、会员位置、会员信誉值和预订任务限额在重新定价过程中保持不变。
2. 新价格主要通过改变会员对任务的收益判断影响任务完成概率。
3. 第一问建立的 Logistic 回归模型可以用于预测不同价格下任务的完成概率。
4. 平台允许对不同任务设置不同价格，但价格调整幅度应保持在合理范围内。
5. 本问暂不考虑任务打包发布的情况，任务仍按单个任务独立定价。
6. 新定价方案既要提高任务完成概率，也要控制平台总成本。

------

| $p_i^0$          | 原价格下第 $i$ 个任务的预测完成概率 |
| $p_i^*$          | 新价格下第 $i$ 个任务的预测完成概率 |
| $d_{i,\min}$     | 第 $i$ 个任务到最近会员的距离       |
| $N_i$            | 第 $i$ 个任务周边会员数量           |
| $\overline{C_i}$ | 第 $i$ 个任务周边会员平均信誉值     |
| $\overline{Q_i}$ | 第 $i$ 个任务周边会员平均预订限额   |
| $D_i$            | 第 $i$ 个任务周边任务密度           |
| $R_i$            | 第 $i$ 个任务竞争强度               |
| $V_i$            | 第 $i$ 个任务单位距离价格           |
| $H_i$            | 第 $i$ 个任务单位竞争价格           |
| $\theta$         | 任务完成概率判定阈值                |
| $C_0$            | 原方案总成本                        |
| $C_1$            | 新方案总成本                        |

------

# 4. 模型建立

## 4.1 原方案完成概率计算

根据第一问建立的 Logistic 回归模型，原价格 $P_i^0$ 下第 $i$ 个任务的完成概率为：
$$
p_i^0=\frac{1}{1+\exp(-Z_i^0)}
$$
其中：
$$
Z_i^0=\alpha_0+\alpha_1P_i^0+\alpha_2d_{i,\min}+\alpha_3N_i+\alpha_4\overline{C_i}
+\alpha_5\overline{Q_i}+\alpha_6D_i+\alpha_7R_i+\alpha_8V_i^0+\alpha_9H_i^0
$$
其中：
$$
V_i^0=\frac{P_i^0}{d_{i,\min}+0.1}
$$
这里 $V_i^0$ 表示原价格下的单位距离价格，$H_i^0$ 表示原价格下的单位竞争价格。

------

## 4.2 新定价下完成概率计算

设第 $i$ 个任务的新定价为 $P_i^*$，则新定价下的单位距离价格为：
$$
V_i^*=\frac{P_i^*}{d_{i,\min}+0.1}
$$
新定价下的单位竞争价格为：
$$
H_i^*=\frac{P_i^*}{D_i+1}
$$
将新价格代入 Logistic 模型，得到新方案下第 $i$ 个任务的预测完成概率：
$$
p_i^*=\frac{1}{1+\exp(-Z_i^*)}
$$
其中：
$$
Z_i^*=\alpha_0+\alpha_1P_i^*+\alpha_2d_{i,\min}+\alpha_3N_i+\alpha_4\overline{C_i}
+\alpha_5\overline{Q_i}+\alpha_6D_i+\alpha_7R_i+\alpha_8V_i^*+\alpha_9H_i^*
$$
也就是说，在第二问中，任务位置、会员分布和任务密度等因素保持不变，主要通过调整 $P_i^*$ 改变 $p_i^*$。

------

## 4.3 定价优化目标

第二问的目标是：在控制总成本的基础上，提高任务完成概率。

因此，可以建立如下优化目标：
$$
\max \sum_{i=1}^{n}p_i^*
$$
该目标表示最大化所有任务的预测完成概率总和，也可以理解为最大化预计完成任务数。

同时，为避免无限制提高价格，需要控制新方案总成本。原方案总成本为：
$$
C_0=\sum_{i=1}^{n}P_i^0
$$
新方案总成本为：
$$
C_1=\sum_{i=1}^{n}P_i^*
$$
成本增长率为：
$$
\eta=\frac{C_1-C_0}{C_0}
$$
为了控制平台支出，可设置成本约束：
$$
C_1\leq (1+\eta_{\max})C_0
$$
其中，$\eta_{\max}$ 表示允许的最大成本增长率。

------

## 4.4 定价约束条件

任务价格不能任意变化，需要满足一定约束。

首先，新价格不低于原价格：
$$
P_i^*\geq P_i^0
$$
这是因为第二问主要目标是提高任务完成率，若降低价格，可能进一步降低任务吸引力。

其次，单个任务涨价幅度不能过大：
$$
P_i^*\leq P_i^0+\Delta_{\max}
$$
其中，$\Delta_{\max}$ 表示单个任务允许的最大涨价幅度。

因此，第 $i$ 个任务的新价格满足：
$$
P_i^0\leq P_i^*\leq P_i^0+\Delta_{\max}
$$

------

## 4.5 完成概率约束

第一问中通过 Logistic 模型确定了较合理的分类阈值：
$$
\theta=0.62
$$
因此，在第二问中，可以将 $\theta$ 作为任务达到较高完成可能性的参考阈值。

对于原预测完成概率较低的任务，希望通过调价使其完成概率尽量达到该阈值：
$$
p_i^*\geq \theta
$$
但由于存在成本限制，不能保证所有任务都达到该阈值。因此，实际求解时可采用如下策略：

> 对预测完成概率低于阈值的任务优先调价；若成本约束允许，则提高其价格至完成概率达到阈值；若成本约束不足，则优先调整单位成本提升效果更好的任务。

------

# 5. 定价优化模型

综合上述目标和约束，可建立如下任务定价优化模型：
$$
\max \sum_{i=1}^{n}p_i^*
$$
约束条件为：
$$
p_i^*=\frac{1}{1+\exp(-Z_i^*)}
$$
该模型的含义是：

> 在价格调整幅度和总成本增长受限的条件下，选择每个任务的新价格，使所有任务的预测完成概率之和最大。

------

# 6. 模型求解思路

由于 Logistic 函数中包含非线性项，且每个任务价格都会影响其预测完成概率，因此该模型属于非线性优化问题。

考虑到本题任务数量为 835 个，直接求解复杂非线性规划较繁琐。因此，可以采用**离散搜索 + 贪心调整**的方法求解。

------

## Step 1：计算原方案完成概率

将原始价格 $P_i^0$ 代入第一问 Logistic 模型，计算每个任务在原方案下的预测完成概率 $p_i^0$。

------

## Step 2：筛选低完成概率任务

根据第一问得到的分类阈值 $\theta=0.62$，筛选满足：
$$
p_i^0<\theta
$$
的任务，作为重点调价对象。

这些任务在原价格下完成概率较低，是新定价方案重点改善的任务。

------

## Step 3：计算候选新价格

对每一个低完成概率任务，从原价格 $P_i^0$ 开始，以一定步长逐步提高价格，直到满足：
$$
p_i^*\geq \theta
$$
或达到最大允许价格：
$$
P_i^*=P_i^0+\Delta_{\max}
$$
得到该任务的候选新价格。

如果某任务在允许涨价范围内可以达到阈值，则取达到阈值所需的最低价格作为候选新价格。

如果某任务即使达到最大允许价格仍无法达到阈值，则取最大允许价格作为候选新价格。

------

## Step 4：计算单位成本提升效果

对于每个候选调价任务，计算其完成概率提升量：
$$
\Delta p_i=p_i^*-p_i^0
$$
计算其价格增加量：
$$
\Delta P_i=P_i^*-P_i^0
$$
定义单位成本提升效果：
$$
E_i=\frac{\Delta p_i}{\Delta P_i}
$$
其中，$E_i$ 越大，说明每增加 1 单位价格带来的完成概率提升越明显，该任务越值得优先调价。

------

## Step 5：按单位成本提升效果排序

将所有候选调价任务按照 $E_i$ 从大到小排序。

在总成本约束下，优先调整 $E_i$ 较大的任务，使有限的成本增加尽可能带来更大的完成概率提升。

------

## Step 6：得到最终新定价方案

从排序后的任务开始依次调价，直到达到总成本约束：
$$
\sum_{i=1}^{n}P_i^*\leq (1+\eta_{\max})\sum_{i=1}^{n}P_i^0
$$
若某任务未被选中调价，则保持原价格：
$$
P_i^*=P_i^0
$$
最终得到附件一所有任务的新价格方案。

------

# 7. 新旧方案比较指标

为了评价新定价方案是否优于原方案，本文从成本和完成效果两个方面进行比较。

## 7.1 总成本比较

原方案总成本：
$$
C_0=\sum_{i=1}^{n}P_i^0
$$
新方案总成本：
$$
C_1=\sum_{i=1}^{n}P_i^*
$$
成本增长率：
$$
\eta=\frac{C_1-C_0}{C_0}
$$

------

## 7.2 平均价格比较

原方案平均价格：
$$
\overline{P^0}=\frac{1}{n}\sum_{i=1}^{n}P_i^0
$$
新方案平均价格：
$$
\overline{P^*}=\frac{1}{n}\sum_{i=1}^{n}P_i^*
$$

------

## 7.3 预测完成率比较

原方案预测完成率：
$$
R_0=\frac{1}{n}\sum_{i=1}^{n}I(p_i^0\geq \theta)
$$
新方案预测完成率：
$$
R_1=\frac{1}{n}\sum_{i=1}^{n}I(p_i^*\geq \theta)
$$
如果：
$$
R_1>R_0
$$
说明新方案能够提高预测完成率。

------

## 7.4 期望完成任务数比较

由于 Logistic 模型输出的是完成概率，因此还可以用完成概率总和表示期望完成任务数。

原方案期望完成任务数：
$$
M_0=\sum_{i=1}^{n}p_i^0
$$
新方案期望完成任务数：
$$
M_1=\sum_{i=1}^{n}p_i^*
$$
若：
$$
M_1>M_0
$$
说明新方案在期望意义下能够提高任务完成数量。

------

## 7.5 单位成本提升效果

为了衡量成本增加是否值得，定义单位成本完成提升指标：
$$
G=\frac{M_1-M_0}{C_1-C_0}
$$
其中，$G$ 表示每增加 1 单位任务成本所带来的期望完成任务数提升。

$G$ 越大，说明新定价方案越经济。

------

# 8. 模型结果应如何解释

第二问求解完成后，应重点从以下几个方面解释：

第一，新方案是否提高了预测完成率。

如果新方案下 $R_1>R_0$，说明通过调价后，更多任务的完成概率达到判定阈值。

第二，新方案是否提高了期望完成任务数。

如果 $M_1>M_0$，说明从概率意义上看，新方案能够提高总体完成效果。

第三，新方案的成本增长是否合理。

如果成本增长率 $\eta$ 较小，而完成率提升明显，说明新方案比原方案更优。

第四，调价主要集中在哪些任务上。

如果调价主要集中在低完成概率、任务密度较高、单位竞争价格较低的任务上，说明新方案能够针对第一问发现的问题进行改进。

------

# 9. 本问模型总结

第二问建立的是：

> **基于 Logistic 完成概率的任务定价优化模型。**

该模型以任务新价格 $P_i^*$ 为决策变量，以最大化预测完成概率总和为目标，在总成本增长和单任务涨价幅度约束下，确定每个任务的新价格。

该模型的优点是能够与第一问自然衔接：第一问用 Logistic 回归解释任务未完成原因，第二问继续利用 Logistic 模型预测新价格下的完成概率，并通过成本、完成率和期望完成任务数等指标与原定价方案进行比较。

taskLat = taskLat(validTask);
taskLon = taskLon(validTask);

pcand = p0;

for t = 1:length(lowIdx)
    
    i = lowIdx(t);
    
    % 从原价格逐步增加到最大允许价格
    priceGrid = P0(i):priceStep:(P0(i) + deltaMax);
    
    % 计算该任务在不同价格下的完成概率
    pGrid = predictProbByPrice(priceGrid, i, alpha, mu_logit, sigma_logit, ...
        di_min, Ni, avgC, avgQ, taskDensity, competitionIndex);
    
    % 找到第一个达到目标完成概率的价格
    hit = find(pGrid >= targetProb, 1, 'first');
    
    if ~isempty(hit)
        bestGridIdx = hit;
    else
        % 如果达不到目标完成概率，则选择概率最高的价格
        [~, bestGridIdx] = max(pGrid);
    end
    
    Pcand(i) = priceGrid(bestGridIdx);
    pcand(i) = pGrid(bestGridIdx);
    
    deltaP(i) = Pcand(i) - P0(i);
    deltaProb(i) = pcand(i) - p0(i);
    
    % 单位成本提升效果
    if deltaP(i) > 0 && deltaProb(i) > 0
        efficiency(i) = deltaProb(i) / deltaP(i);
    end

                pnew(i) = partialProb;

            end

    end

function [lat, lon] = parseGPSAuto(gpsCol, taskLatCenter, taskLonCenter)
    % 自动解析会员 GPS
    % 支持 "纬度 经度"、"经度 纬度"、逗号分隔等格式
    % 通过比较两种顺序到任务中心的距离，自动选择更合理的顺序

    gpsStr = string(gpsCol);
    N = length(gpsStr);

    lat = nan(N, 1);
    lon = nan(N, 1);

    for i = 1:N
        s = gpsStr(i);

        nums = regexp(s, '[-+]?\d+\.?\d*', 'match');
        
        if length(nums) < 2
            continue;
        end

        a = str2double(nums{1});
        b = str2double(nums{2});

        % 候选 1：a 是纬度，b 是经度
        lat1 = a;
        lon1 = b;

        % 候选 2：a 是经度，b 是纬度
        lat2 = b;
        lon2 = a;

        valid1 = isValidLatLon(lat1, lon1);
        valid2 = isValidLatLon(lat2, lon2);

        d1 = inf;
        d2 = inf;

        if valid1
            d1 = geoDistanceKm(taskLatCenter, taskLonCenter, lat1, lon1);
        end

        if valid2
            d2 = geoDistanceKm(taskLatCenter, taskLonCenter, lat2, lon2);
        end

        if d1 <= d2
            lat(i) = lat1;
            lon(i) = lon1;
        else
            lat(i) = lat2;
            lon(i) = lon2;
        end
    end
end

function flag = isValidLatLon(lat, lon)
    % 判断经纬度是否合法
    flag = ~isnan(lat) && ~isnan(lon) && ...
           lat >= -90 && lat <= 90 && ...
           lon >= -180 && lon <= 180;
end

function d = geoDistanceKm(lat1, lon1, lat2, lon2)
    % 经纬度近似距离公式
    % 输入可以为标量或向量
    % 输出单位：km

    d = 111 * sqrt( ...
        (lat1 - lat2).^2 + ...
        ((lon1 - lon2) .* cosd(lat1)).^2 ...
        );
end

function [Xstd, mu, sigma] = standardizeData(X)
    % 标准化数据
    mu = mean(X, 1, 'omitnan');
    sigma = std(X, 0, 1, 'omitnan');

    sigma(sigma == 0) = 1;

    Xstd = (X - mu) ./ sigma;
end

function loss = logisticNLL(alpha, X, Y)
    % Logistic 回归负对数似然函数

    Z = X * alpha;
    p = sigmoid(Z);

    epsVal = 1e-10;
    p = min(max(p, epsVal), 1 - epsVal);

    loss = -sum(Y .* log(p) + (1 - Y) .* log(1 - p));

    % 加入很小的正则项，增强数值稳定性
    loss = loss + 1e-6 * sum(alpha(2:end).^2);
end

function p = sigmoid(Z)
    % Sigmoid 函数
    p = 1 ./ (1 + exp(-Z));
end

function p = predictProbByPrice(priceValue, i, alpha, mu_logit, sigma_logit, ...
    di_min, Ni, avgC, avgQ, taskDensity, competitionIndex)
    % 给定某个任务的新价格，计算其 Logistic 预测完成概率
    %
    % priceValue 可以是标量，也可以是价格向量

    priceValue = priceValue(:);

    di = di_min(i) * ones(size(priceValue));
    ni = Ni(i) * ones(size(priceValue));
    ac = avgC(i) * ones(size(priceValue));
    aq = avgQ(i) * ones(size(priceValue));
    td = taskDensity(i) * ones(size(priceValue));
    ci = competitionIndex(i) * ones(size(priceValue));

    v = priceValue ./ (di + 0.1);
    h = priceValue ./ (td + 1);

    Xraw = [priceValue, di, ni, ac, aq, td, ci, v, h];

    Xstd = (Xraw - mu_logit) ./ sigma_logit;

    Xdesign = [ones(size(Xstd, 1), 1), Xstd];

    p = sigmoid(Xdesign * alpha);
end

# 5. 算法求解步骤

**Step 1：读取并清洗原始数据**

程序首先读取附件一中的任务数据和附件二中的会员数据，提取任务编号、任务经纬度、任务原始价格、任务完成情况，以及会员位置、信誉值和预订任务限额。随后对缺失值和异常会员位置进行处理，剔除明显远离任务区域的异常会员点，保证后续距离计算和空间分析的可靠性。

**Step 2：构造任务空间特征**

程序根据任务和会员的经纬度，计算每个任务到所有会员的距离，并提取每个任务到最近会员的距离。同时，以每个任务为中心，统计 3 km 范围内的会员数量、平均信誉值和平均预订限额，用来描述任务周边的会员资源情况。

**Step 3：构造任务竞争特征**

程序继续以每个任务为中心，统计 3 km 范围内的其他任务数量，得到任务密度。然后结合任务密度和周边会员数量，构造竞争强度指标，并根据任务价格计算单位距离价格和单位竞争价格，用来反映任务在空间竞争环境中的价格吸引力。

**Step 4：训练 Logistic 完成概率模型**

程序将任务价格、最近会员距离、周边会员数量、平均信誉值、平均预订限额、任务密度、竞争强度、单位距离价格和单位竞争价格作为自变量，将任务是否完成作为因变量，重新训练 Logistic 回归模型。训练完成后，得到每个变量对应的回归系数，并计算原方案下每个任务的预测完成概率。

**Step 5：评价原定价方案**

程序根据原始任务价格计算原方案总成本、平均任务价格、期望完成任务数、预测完成率和低完成概率任务数量。这里将预测完成概率低于 0.62 的任务定义为低完成概率任务，作为后续重点调价对象。

**Step 6：筛选候选调价任务**

程序筛选出原预测完成概率低于 0.62 的任务，将这些任务作为候选调价任务。对于预测完成概率已经达到 0.62 及以上的任务，认为其完成可能性较高，原则上保持原价格不变。

**Step 7：生成候选新价格**

对于每一个候选调价任务，程序从原价格开始，以 0.5 为步长逐步提高价格，并重新计算该价格下的预测完成概率。当任务预测完成概率达到 0.62 时，停止继续涨价，并记录该价格作为候选新价格。若任务涨价达到最大允许幅度 10 后仍未达到 0.62，则取该范围内预测完成概率最高的价格作为候选新价格。

**Step 8：计算调价优先级**

程序计算每个候选调价任务的价格增加量和预测完成概率提升量，并进一步计算单位成本提升效果。单位成本提升效果越大，说明该任务每增加 1 单位价格所带来的完成概率提升越明显，因此越应该优先调价。

**Step 9：在成本约束下进行贪心调价**

程序将所有候选调价任务按照单位成本提升效果从大到小排序。在总成本增长不超过 5% 的约束下，依次对排序靠前的任务采用候选新价格，直到成本约束达到上限或所有候选任务处理完毕。未被选中调价的任务保持原价格不变。

**Step 10：输出新定价方案并比较结果**

程序得到所有任务的新价格后，重新计算新方案下每个任务的预测完成概率，并统计新方案总成本、平均价格、期望完成任务数、预测完成率和低完成概率任务数量。最后将这些指标与原方案进行对比，判断新定价方案是否优于原定价方案。

**Step 11：绘制结果图像**

程序绘制原价格与新价格对比图、价格增加量分布图、调价前后预测完成概率分布图、预测完成概率对比图、调价任务空间分布图和调价过程效果变化图，用于直观展示新方案的价格调整情况和完成概率提升效果。
