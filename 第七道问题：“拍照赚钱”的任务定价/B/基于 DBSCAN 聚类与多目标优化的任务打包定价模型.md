# 第三问：基于 DBSCAN 聚类与多目标优化的任务打包定价模型

## 1. 模型总体思路

第三问需要在第二问单任务优化定价的基础上，进一步考虑空间位置集中的任务是否可以打包发布。因此，本问需要同时解决两个问题：

1. 根据任务经纬度判断哪些任务可以组成任务包；
2. 在任务打包后，重新确定每个任务包的价格，并兼顾任务完成效果和平台成本。

本文建立“DBSCAN 空间聚类—任务包构造—多目标定价优化—Logistic 完成概率评价”的组合模型。

具体思路为：

首先，利用 DBSCAN 聚类算法识别空间上相互邻近的任务，将同一聚类内的任务组成候选任务包；其次，以第二问多目标优化得到的任务价格作为打包前的基准价格，根据任务包空间紧凑程度和包内低完成概率任务比例确定任务包价格的可调整范围；再次，以任务包总价格为决策变量，建立最大化期望完成任务数和最小化平台总成本的多目标优化模型；最后，将任务包价格按比例分配为包内任务的等效价格，并代入 Logistic 模型，评价打包方案下的任务完成效果。

模型名称可写为：

> **基于 DBSCAN 聚类与加权多目标优化的任务打包定价模型**

------

# 2. 问题分析

第二问是在所有任务单独发布的条件下进行价格优化，得到每个任务的多目标优化价格和预测完成概率。第三问进一步指出，当多个任务的位置比较集中时，可以将这些任务组合成任务包发布。

任务打包具有两方面作用。一方面，会员到达某一区域后，可以在一次出行过程中完成多个邻近任务，从而减少重复出行；另一方面，任务包包含多个任务，其整体价格和任务数量也可能影响会员的接取意愿。

因此，第三问不能只进行空间聚类，也不能只进行价格优化，而需要将任务分组与任务包定价结合起来。

本问可以分为三个子问题：

第一，利用任务经纬度识别空间密集区域，确定哪些任务适合打包；

第二，以第二问的多目标优化价格作为基准，确定每个任务包的合理价格；

第三，预测任务打包后的完成概率，并与第二问的单任务优化方案进行比较。

从问题类型上看，本问属于：

> 空间聚类问题、组合优化问题、多目标定价优化问题和概率评价问题。

------

# 3. 模型假设

1. 任务打包过程中，任务位置、会员位置、会员信誉值、会员预订限额等非价格因素保持不变。
2. 空间距离较近的任务更适合由同一会员连续完成，因此可将其组成任务包。
3. 同一任务只能属于一个任务包，不允许任务重复打包。
4. 规模较小的空间孤立任务仍按照第二问方案单独发布。
5. 一个任务包内的任务数量不能过多，以避免超过会员的实际执行能力。
6. 第二问多目标优化得到的任务价格，是任务单独发布情况下的合理基准价格。
7. 附件中没有真实的任务包执行数据，因此无法重新训练任务包完成概率模型。本文将任务包价格分配为包内任务的等效价格，再利用第一问建立的 Logistic 模型进行情景预测。
8. 任务包价格可以围绕第二问包内价格总和上下调整，但调整幅度需要受到限制。
9. 平台希望在不降低整体期望完成效果的前提下，尽量控制任务包总成本。

------

# 5. 模型建立

## 5.1 任务空间距离模型

设第 (i) 个任务的经纬度为 ((lon_i,lat_i))，第 (j) 个任务的经纬度为 ((lon_j,lat_j))。

任务之间的近似地理距离为：

# [ g_{ij}

111\sqrt{
(lat_i-lat_j)^2
+
\left[(lon_i-lon_j)\cos(lat_i)\right]^2
}
]

其中，距离单位为 km。

当 (g_{ij}) 较小时，说明任务 (i) 和任务 (j) 的空间位置接近，具备组合成任务包的可能性。

在程序实现中，也可以采用 Haversine 球面距离公式，以提高距离计算精度：

# [ g_{ij}

2R\arcsin
\sqrt{
\sin^2\left(\frac{\Delta \varphi}{2}\right)
+
\cos\varphi_i\cos\varphi_j
\sin^2\left(\frac{\Delta \lambda}{2}\right)
}
]

其中，(R=6371) km 为地球平均半径。

------

## 5.2 DBSCAN 空间聚类模型

DBSCAN 通过邻域半径 (\varepsilon) 和最少邻域任务数 (MinPts) 识别任务密集区域。

对于任务 (i)，定义其 (\varepsilon) 邻域为：

# [ N_{\varepsilon}(i)

\left{
j\mid g_{ij}\leq\varepsilon
\right}
]

若任务 (i) 的邻域任务数量满足：

[
\left|N_{\varepsilon}(i)\right|
\geq MinPts
]

则任务 (i) 被定义为核心任务。

若某任务本身不是核心任务，但位于某个核心任务的邻域内，则该任务为边界任务。

既不是核心任务，也不属于任何核心任务邻域的任务，被定义为噪声任务。

DBSCAN 将密度可达的核心任务和边界任务划分到同一聚类中。每一个聚类可以作为一个候选任务包或候选任务包集合。

与普通 K-means 聚类相比，DBSCAN 不需要预先确定任务包数量，并且可以直接识别空间孤立任务，更符合题目中“部分任务位置比较集中”的特征。

------

## 5.3 DBSCAN 参数选择

DBSCAN 的聚类结果主要受到 (\varepsilon) 和 (MinPts) 的影响。

如果 (\varepsilon) 太小，大量任务会被识别为噪声任务，难以形成有效任务包；如果 (\varepsilon) 太大，可能将距离较远的任务划分到同一聚类中。

因此，本文不直接人为指定唯一的 (\varepsilon)，而是在候选范围内进行参数搜索。

对每一组候选参数：

[
(\varepsilon,MinPts)
]

分别执行以下过程：

1. 使用 DBSCAN 形成候选任务包；
2. 对过大的聚类进行拆分；
3. 建立任务包定价优化模型；
4. 计算第三问综合目标函数；
5. 选择综合目标函数最大的参数组合。

因此，DBSCAN 参数的最终选择标准不是单纯追求聚类数量最多，而是追求：

> 任务空间分组与任务包定价共同作用下的整体方案最优。

也可以利用 (k)-距离曲线的拐点，为 (\varepsilon) 的候选范围提供参考。

------

## 5.4 任务包规模约束与聚类后处理

DBSCAN 得到的某些聚类可能包含较多任务。若直接将整个聚类作为一个任务包，可能导致包内任务数量过多，降低会员接取意愿。

因此，对任务包规模设置约束：

[
2\leq m_k\leq m_{\max}
]

其中，(m_{\max}) 为任务包允许包含的最大任务数。

对于任务数量满足上述要求的聚类，直接作为一个任务包。

对于任务数超过 (m_{\max}) 的聚类，采用距离优先的贪心拆分方法：

1. 选择一个尚未分组的任务作为起点；
2. 按照任务之间的距离从小到大选择邻近任务；
3. 直到任务包任务数达到 (m_{\max})；
4. 对剩余任务继续执行上述过程。

对于 DBSCAN 识别出的噪声任务以及拆分后无法组成两个及以上任务的小规模集合，仍按照第二问方案单独发布。

最终得到的任务包集合满足：

[
\bigcup_{k=1}^{K}G_k={1,2,\ldots,n}
]

且对于任意 (k\neq l)，有：

[
G_k\cap G_l=\varnothing
]

即每个任务只属于一个发布单元。

------

## 5.5 任务包空间紧凑程度

设第 (k) 个任务包的中心位置为：

# [ \overline{lon}_k

\frac{1}{m_k}
\sum_{i\in G_k}lon_i
]

# [ \overline{lat}_k

\frac{1}{m_k}
\sum_{i\in G_k}lat_i
]

定义任务包内任务到包中心的平均距离为：

# [ L_k

\frac{1}{m_k}
\sum_{i\in G_k}
d\left(i,\overline G_k\right)
]

其中，(d(i,\overline G_k)) 表示任务 (i) 到任务包中心的距离。

为了将空间离散程度转换为 (0) 到 (1) 范围内的紧凑系数，定义：

# [ \lambda_k

\max
\left{
0,,
1-\frac{L_k}{\varepsilon}
\right}
]

当包内任务距离较近时，(L_k) 较小，(\lambda_k) 较大；当任务包比较分散时，(\lambda_k) 较小。

因此，(\lambda_k) 越大，表示任务包越紧凑，会员连续完成包内任务越方便。

------

## 5.6 第二问基准价格与低完成概率比例

对于第 (k) 个任务包，其第二问优化价格总和为：

# [ S_{2k}

\sum_{i\in G_k}P_i^{(2)}
]

该价格表示包内任务在单独发布条件下的平台总支出，是第三问任务包定价的比较基准。

定义任务包内低完成概率任务比例：

# [ q_k

\frac{1}{m_k}
\sum_{i\in G_k}
I\left(p_i^{(2)}<\theta\right)
]

其中：

[
\theta=0.62
]

若 (q_k) 较大，说明该任务包中包含较多第二问方案下仍未达到目标完成概率的任务，需要给予更大的价格补偿空间。

若 (q_k=0)，说明包内所有任务在第二问方案下均已达到目标完成概率，任务包价格可以更偏向成本节约。

------

## 5.7 任务包价格决策模型

将第 (k) 个任务包的总价格 (B_k) 作为决策变量。

空间紧凑任务包能够减少重复出行，因此允许相对于第二问包内价格总和进行一定折扣；低完成概率任务较多的任务包则需要保留一定的价格补偿空间。

任务包价格下限定义为：

# [ B_k^{\min}

S_{2k}
\left(
1-\delta_d\lambda_k
\right)
]

其中，(\delta_d) 为最大折扣比例。

任务包越紧凑，(\lambda_k) 越大，允许的最大折扣幅度越大。

任务包价格上限定义为：

# [ B_k^{\max}

S_{2k}
\left(
1+\delta_cq_k
\right)
]

其中，(\delta_c) 为低完成概率任务的最大补偿比例。

任务包价格满足：

[
B_k^{\min}
\leq B_k
\leq B_k^{\max}
]

即：

[
S_{2k}(1-\delta_d\lambda_k)
\leq B_k
\leq
S_{2k}(1+\delta_cq_k)
]

对于单独发布任务，保持第二问价格不变：

[
B_k=P_i^{(2)},\qquad m_k=1
]

这样可以使第三问的优化效果主要来源于任务打包，而不是再次全面调整所有单任务价格。

------

## 5.8 任务包价格的等效分配

由于第一问的 Logistic 模型以单个任务价格作为输入，因此需要将任务包总价格分配为包内各任务的等效价格。

本文按照第二问价格比例进行分配。

定义任务 (i) 在任务包 (k) 中的价格权重为：

# [ w_{ik}

\frac{P_i^{(2)}}{S_{2k}}
]

显然有：

[
\sum_{i\in G_k}w_{ik}=1
]

第三问方案下任务 (i) 的等效价格为：

# [ \widetilde P_i

# w_{ik}B_k

B_k
\frac{P_i^{(2)}}{S_{2k}}
]

并满足：

[
\sum_{i\in G_k}\widetilde P_i=B_k
]

该分配方式保持了包内任务原有价格的相对比例。第二问价格较高的任务，在任务包中分配到的等效价格也相对较高。

------

## 5.9 打包方案下的完成概率预测

根据第三问的等效价格，重新计算单位距离价格和单位竞争价格：

# [ \widetilde V_i

\frac{\widetilde P_i}
{d_{i,\min}+0.1}
]

# [ \widetilde H_i

\frac{\widetilde P_i}
{D_i+1}
]

将等效价格及其相关变量标准化后，代入第一问建立的 Logistic 模型：

# [ \widetilde p_i

\frac{1}
{1+\exp(-\widetilde Z_i)}
]

其中：

[
\begin{aligned}
\widetilde Z_i={}&
\alpha_0
+\alpha_1\widetilde P_i^s
+\alpha_2d_{i,\min}^s
+\alpha_3N_i^s
+\alpha_4\overline C_i^s \
&+\alpha_5\overline Q_i^s
+\alpha_6D_i^s
+\alpha_7R_i^s
+\alpha_8\widetilde V_i^s
+\alpha_9\widetilde H_i^s
\end{aligned}
]

其中，Logistic 模型的标准化参数和回归系数均与第二问保持一致。

需要说明的是，由于没有任务包真实执行数据，(\widetilde p_i) 表示任务包价格折算后的情景预测概率，而不是实际观测到的任务包完成率。

# 6. 多目标定价优化模型

## 6.1 目标一：最大化期望完成任务数

第三问打包方案下的期望完成任务数为：

# [ M_3

\sum_{i=1}^{n}\widetilde p_i
]

第一个优化目标为：

[
\max M_3
]

该目标表示希望通过任务打包和价格调整，提高所有任务预测完成概率之和。

------

## 6.2 目标二：最小化平台总成本

第三问方案总成本为：

# [ C_3

\sum_{k=1}^{K}B_k
]

第二个优化目标为：

[
\min C_3
]

该目标表示平台希望在提高任务完成效果的同时，尽量减少任务包定价总成本。

------

## 6.3 多目标函数归一化

第二问期望完成任务数为 (M_2)，第三问相对第二问的归一化完成效果提升为：

# [ F_1^{(3)}

\frac{M_3-M_2}
{n-M_2}
]

第三问相对第二问的成本变化率为：

# [ F_2^{(3)}

\frac{C_3-C_2}
{C_2}
]

其中，(F_1^{(3)}) 越大越好，(F_2^{(3)}) 越小越好。

------

## 6.4 加权综合目标函数

引入完成效果权重 (\omega_3)，构造综合目标函数：

# [ \max J_3

## \omega_3F_1^{(3)}

(1-\omega_3)F_2^{(3)}
]

即：

# [ \max J_3

## \omega_3 \frac{M_3-M_2} {n-M_2}

(1-\omega_3)
\frac{C_3-C_2}
{C_2}
]

当 (\omega_3) 较大时，模型更重视提高任务完成效果；当 (\omega_3) 较小时，模型更重视控制任务包成本。

为了与第二问保持一致，第三问可先取：

[
\omega_3=0.70
]

再通过权重敏感性分析检验模型稳定性。

------

# 7. 约束条件

## 7.1 任务包价格范围约束

[
S_{2k}(1-\delta_d\lambda_k)
\leq B_k
\leq
S_{2k}(1+\delta_cq_k)
]

------

## 7.2 平台总成本约束

设第三问相对于第二问允许的最大成本增长率为 (\eta_3)，则：

[
C_3
\leq
(1+\eta_3)C_2
]

即：

[
\sum_{k=1}^{K}B_k
\leq
(1+\eta_3)
\sum_{i=1}^{n}P_i^{(2)}
]

------

## 7.3 完成效果保护约束

为了避免模型仅通过大幅降价来减少成本，而导致任务完成效果下降，可设置：

[
M_3\geq M_2
]

即第三问方案的期望完成任务数不能低于第二问方案。

这一约束保证任务打包方案至少不能削弱第二问已经取得的完成效果。

------

## 7.4 任务包规模约束

[
2\leq m_k\leq m_{\max}
]

对于单独发布任务：

[
m_k=1
]

------

## 7.5 任务唯一归属约束

每个任务必须且只能属于一个发布单元：

[
\sum_{k=1}^{K}x_{ik}=1
]

其中，若任务 (i) 属于任务包 (k)，则：

[
x_{ik}=1
]

否则：

[
x_{ik}=0
]

------

## 7.6 离散价格约束

任务包价格按照固定步长 (h_3) 调整：

# [ B_k

S_{2k}+s_kh_3
]

其中，(s_k) 为整数，可以取正值、零或负值，但必须满足任务包价格上下限约束。

------

# 8. 方案评价指标

除综合目标函数外，还需要利用以下指标评价第三问方案。

第三问预测完成率为：

# [ R_3

\frac{1}{n}
\sum_{i=1}^{n}
I(\widetilde p_i\geq\theta)
]

第三问低完成概率任务数为：

# [ L_3

\sum_{i=1}^{n}
I(\widetilde p_i<\theta)
]

任务包覆盖率为：

# [ R_{\mathrm{pack}}

# 10. 模型的核心优点

该模型具有以下特点。

第一，DBSCAN 能够根据任务实际空间分布自动识别任务密集区域，不需要预先指定任务包数量。

第二，噪声任务可以自然地作为单独任务发布，不需要强制将所有任务进行打包。

第三，任务包价格以第二问多目标优化价格为基准，使第三问与第二问能够自然衔接。

第四，任务包价格范围同时考虑了空间紧凑程度和低完成概率任务比例，既体现了打包带来的出行便利，也照顾了较难完成的任务。

第五，第三问继续采用最大化期望完成任务数和最小化平台成本的多目标思想，使整篇论文的优化目标保持一致。

第六，模型所有步骤都可以在 MATLAB 中实现，后续可以采用 DBSCAN、距离矩阵计算和离散贪心搜索完成数值求解。

最终可将第三问概括为：

> 本文首先利用 DBSCAN 算法识别空间位置集中的任务，并结合任务包规模约束构造任务包；然后以第二问多目标优化价格为基准，将任务包总价格作为决策变量，建立最大化期望完成任务数和最小化平台总成本的加权多目标优化模型；最后通过等效价格分配和 Logistic 回归模型预测任务完成概率，从而得到任务打包后的优化定价方案。
