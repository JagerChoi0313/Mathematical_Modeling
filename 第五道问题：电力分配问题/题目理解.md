你好，我已经把题目和“做题要求”都读了一遍。先不急着算，这道题最重要的是先理解它到底在让我们干什么。它不是单纯的“电力计算题”，本质上是一个 **“市场竞价 + 输电线路安全约束 + 优化调度”** 的数学建模题。题目里的 8 台发电机组、6 条主要输电线路，以及各机组报价、爬坡速率、线路限值，都是为了让我们建立一个安全又经济的调度模型。

## 一、这道题讲的是什么事

你可以把它理解成：

电网公司预测下一时段需要多少电，然后让 8 台发电机组按照报价从低到高竞争发电。谁报价低，谁优先发电。这样得到一个最便宜的初始发电方案。

但是，电不是想怎么送就怎么送。某些线路有输电能力上限，如果某个发电方案导致某条线路上的潮流超过限值，就叫 **输电阻塞**。这时就不能直接执行最便宜的方案，必须调整各机组出力，让线路安全。

所以这道题的核心矛盾是：

> **市场想让便宜机组多发电，但电网安全可能不允许。**

数学建模要解决的就是：

> 在满足负荷需求的前提下，先保证线路不过载，再尽量减少因为调整发电方案带来的阻塞费用。

## 二、几个关键词先搞懂

### 1. 出力

“出力”就是每台发电机组实际发多少电，单位是 MW。

例如方案 0 中，8 台机组当前出力分别是：

[
120,\ 73,\ 180,\ 80,\ 125,\ 125,\ 81.1,\ 90
]

这些是当前时段末的出力预测值，后面算下一时段时，要受到爬坡速率限制。

### 2. 潮流

“潮流”就是某条线路上传输的功率。它可以是正数，也可以是负数。

正负号表示方向，但判断是否阻塞时，看的是绝对值：

[
|F_j| \leq L_j
]

其中 (F_j) 是第 (j) 条线路的潮流，(L_j) 是该线路的安全限值。

所以如果第 3 条线路潮流是 (-170)，限值是 160，那也是超限，因为：

[
|-170|=170>160
]

### 3. 段容量和段价

每台机组把自己的发电能力分成若干段，每一段报一个价格。

例如某机组可能这样报价：

| 段      | 段容量 | 段价        |
| ------- | ------ | ----------- |
| 第 1 段 | 70 MW  | -505 元/MWh |
| 第 2 段 | 0 MW   | 0 元/MWh    |
| 第 3 段 | 50 MW  | 124 元/MWh  |

调度中心按照段价从低到高选，直到总出力等于负荷需求。

段价越低，越优先被选中。

### 4. 清算价

最后一个被选中的段价，就是清算价。

关键点是：不是每台机组按自己的报价结算，而是所有被选中的出力都按清算价结算。题目明确说“该时段全部机组的所有出力均按清算价结算”。

所以初始交易结果类似于：

> 谁便宜谁先上，最后一个入选的报价决定统一结算价格。

### 5. 爬坡速率

机组不能瞬间从 80 MW 跳到 200 MW。题目给了每台机组每分钟最多能增加或减少多少 MW。

因为一个交易时段是 15 分钟，所以第 (i) 台机组下一时段出力必须满足：

[
P_i^{当前}-15r_i \leq P_i \leq P_i^{当前}+15r_i
]

例如 1 号机组当前出力 120 MW，爬坡速率是 2.2 MW/分钟，那么 15 分钟内最多变化：

[
15\times 2.2=33
]

所以下一时段 1 号机组出力范围大约是：

[
87 \leq P_1 \leq 153
]

这一步很重要，第三问和第五问都会用到。

## 三、五个问题分别让你干什么

### 第一问：建立“机组出力 → 线路潮流”的近似模型

题目给了表 1 和表 2。

表 1 是 33 个出力方案，其中方案 0 是基准方案，方案 1—32 是围绕方案 0 改变某一台机组出力后的实验数据。表 2 给出每个方案对应的 6 条线路潮流。

这一问的意思是：

> 根据这些实验数据，找出每条线路潮流和 8 台机组出力之间的近似关系。

最自然的模型是多元线性回归：

[
F_j=b_j+a_{j1}P_1+a_{j2}P_2+\cdots+a_{j8}P_8
]

其中：

- (F_j)：第 (j) 条线路的潮流；
- (P_i)：第 (i) 台机组的出力；
- (a_{ji})：第 (i) 台机组出力变化对第 (j) 条线路潮流的影响系数；
- (b_j)：常数项。

因为有 6 条线路，所以要建立 6 个回归方程。

这一问不是让你推真实电力系统潮流方程，而是让你用数据拟合一个近似模型。做题要求 PPT 也明确提示要自学多元线性回归，并使用数学软件函数做回归分析。

### 第二问：设计阻塞费用计算规则

这一问不是固定答案题，而是让你设计一个“合理、公平”的补偿规则。

为什么会有阻塞费用？

因为初始交易结果是按市场竞价得到的。后来由于线路阻塞，调度中心不得不调整机组出力。调整后会出现两类矛盾：

第一类：原本通过竞价获得发电权的机组，后来被迫少发电。

这部分叫 **序内容量不能出力**。

第二类：原本报价较高、没有获得发电权的机组，后来为了消除阻塞，被迫增加出力。

这部分叫 **序外容量出力**。

题目要求公平对待这两类情况。

比较合理的设计思路是：

[
阻塞费用 = 序内容量被削减的补偿 + 序外容量被调用的补偿
]

可以简单理解为：

- 对于本来该发、后来不能发的低价机组，要补偿它失去的市场收益；
- 对于本来不该发、后来被迫发的高价机组，要补偿它报价高于清算价的部分。

注意，阻塞费用不是总购电费用，而是因为“不能执行初始交易结果”额外产生的补偿费用。

### 第三问：负荷为 982.4 MW 时，按市场规则算初始出力方案

这一问还不考虑线路是否阻塞，只按照市场交易规则算。

步骤是：

1. 根据当前出力和爬坡速率，算出每台机组下一时段可行出力范围；
2. 把所有机组的报价段按段价从低到高排序；
3. 从便宜段开始选容量；
4. 直到总出力等于 982.4 MW；
5. 最后被选中的段价就是清算价；
6. 得到 8 台机组的初始出力分配预案。

这里容易错的一点是：不能只看段价便宜就无限选，还要受爬坡约束限制。

### 第四问：检查第三问方案是否导致输电阻塞，并调整

第三问得到的只是“市场上最便宜”的方案，不一定安全。

第四问要做的是：

先用第一问建立的潮流模型，把第三问得到的 8 台机组出力代进去，算出 6 条线路潮流：

[
F_1,F_2,\ldots,F_6
]

然后检查：

[
|F_j| \leq L_j
]

如果全部满足，说明不阻塞，直接接受第三问方案。

如果有线路超限，就要调整机组出力。调整时要满足：

[
\sum_{i=1}^{8}P_i=982.4
]

同时满足：

[
P_i^{当前}-15r_i \leq P_i \leq P_i^{当前}+15r_i
]

还要满足线路安全约束：

[
|F_j(P_1,\ldots,P_8)| \leq L_j
]

在这些约束下，尽量让阻塞费用最小。

所以第四问其实是一个优化问题。

可以写成：

[
\min \ C_{\text{阻塞}}
]

约束条件包括：

[
\sum P_i=D
]

[
P_i^{min}\leq P_i\leq P_i^{max}
]

[
|F_j|\leq L_j
]

如果完全消除阻塞做不到，再考虑安全裕度：

[
|F_j|\leq L_j(1+\gamma_j)
]

如果连安全裕度都无法满足，才考虑拉闸限电。题目给了每条线路的限值和相对安全裕度。

### 第五问：负荷变成 1052.8 MW，重复第三问和第四问

第五问不是新模型，而是把负荷从 982.4 MW 改成 1052.8 MW。

所以重复：

1. 按市场规则算初始出力预案；
2. 算清算价；
3. 用潮流模型检查线路是否阻塞；
4. 若阻塞，建立优化模型调整出力；
5. 计算阻塞费用。

因为 1052.8 MW 比 982.4 MW 更高，所以机组出力整体更大，线路阻塞的可能性也会增加。

## 四、这道题的主线其实很清楚

整道题可以总结成一条流程：

[
实验数据 \rightarrow 潮流回归模型 \rightarrow 市场竞价出力预案 \rightarrow 阻塞检查 \rightarrow 优化调整 \rightarrow 阻塞费用
]

也就是说：

第一问是在建“电网安全判断工具”；

第二问是在建“经济补偿规则”；

第三问是在算“市场自然形成的便宜方案”；

第四问是在算“安全约束下修正后的方案”；

第五问是在换一个负荷需求，再跑一遍流程。

## 五、你现在最应该抓住的建模思想

这题最关键的不是公式多，而是分清两个层次：

### 第一层：市场层

市场层只关心：

> 哪些机组报价低，谁先发电，清算价是多少。

它对应第三问和第五问的初始预案。

### 第二层：电网安全层

电网安全层关心：

> 这个发电方案会不会让线路过载。

它对应第一问、第四问和第五问的阻塞管理。

真正的模型应该把这两层连起来：

[
市场低价优先 \quad \text{但必须服从} \quad 线路安全约束
]

## 六、这道题最容易踩的坑

第一，不要把潮流限值只看正方向。潮流有正负，判断阻塞看绝对值。

第二，爬坡速率一定要乘以 15，因为每个交易时段是 15 分钟。

第三，清算价不是每台机组自己的报价，而是最后被选中容量的段价。

第四，第三问只是初始交易结果，不代表最终安全调度方案。

第五，阻塞费用不是随便加一个惩罚项，而是要围绕“序内容量少发”和“序外容量多发”来设计。

第六，第一问最好用多元线性回归，而不是硬套复杂电力系统潮流方程。题目给的是实验数据，目的就是让我们从数据中拟合近似表达式。

## 七、我们后面做题的顺序

这道题建议按下面顺序来做：

1. 先做第一问：用表 1、表 2 回归出 6 条潮流表达式；
2. 再做第二问：设计阻塞费用计算公式；
3. 再做第三问：算 982.4 MW 的初始出力预案和清算价；
4. 再做第四问：检查阻塞，建立优化模型调整；
5. 最后做第五问：把负荷换成 1052.8 MW，重复第三、四问。

所以你现在可以先把这道题理解成一句话：

> **根据报价先形成一个便宜的发电计划，再用线路潮流模型检查是否安全；如果不安全，就在满足负荷和线路约束的前提下调整机组出力，并尽量减少由此产生的补偿费用。**
