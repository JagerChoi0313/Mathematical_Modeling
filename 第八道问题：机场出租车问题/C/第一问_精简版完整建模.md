# 问题一：基于分时乘客需求估计的等待时间—净收益阈值决策模型

## 一、模型简化思路

前面的完整模型思路没有问题，但如果把双队列递推、乘客到达时间概率分布、蒙特卡洛模拟、未来出租车持续流入等内容全部放进第一问，会使模型显得过于复杂，也会增加后续数据收集与代码实现难度。

因此，本文将模型简化为：

\[
\boxed{\text{基于分时乘客需求估计的等待时间—净收益阈值决策模型}}
\]

保留三个核心环节：

\[
\text{乘客需求估计}
\rightarrow
\text{司机等待时间估计}
\rightarrow
\text{两种方案收益比较}
\]

---

## 二、可以舍去的内容

### 1. 舍去完整的乘客队列递推

前面的模型同时建立了出租车队列和乘客队列。

但问题一主要研究的是：司机到达机场时，蓄车池中已经存在出租车排队的情况下，未来乘客需求能否及时消化其前方车辆。

因此，不必单独递推乘客等待队列。

### 2. 舍去司机之后进入蓄车池的出租车数量

假设出租车严格按照先到先服务原则排队。

目标司机进入蓄车池后，后来到达的出租车都排在其后方，不会影响目标司机的等待时间。因此，在计算该司机的等待时间时，不需要考虑未来新进入蓄车池的车辆数。

### 3. 简化乘客下机时间分布

原模型使用正态分布或对数正态分布描述乘客从航班落地到乘车区的时间。

精简后，直接使用平均延迟时间：

\[
\tau
\]

例如，假设航班落地后平均经过 30～40 分钟，乘客到达出租车乘车区。

### 4. 暂时舍去蒙特卡洛模拟

第一问主要建立一般模型，不必在主模型中加入大量随机模拟。

不确定因素可在最后通过简单敏感性分析处理，例如：

- 出租车选择率上下变化 10%；
- 市区寻客时间上下变化 20%；
- 航班客座率上下变化 10%。

### 5. 不单独计算等待机会成本

前面模型既将时间成本计入净利润，又使用单位时间收益比较，容易出现重复计算。

精简模型中只计算：

\[
\text{单位时间预期净收益}
=
\frac{\text{单次净利润}}{\text{完成该方案所需总时间}}
\]

这样，等待时间越长，单位时间收益自然越低，不必再额外设置主观时间成本。

---

## 三、问题分析

出租车司机将乘客送到机场后，可以选择以下两种方案：

- 方案 A：进入机场蓄车池排队，等待载客返回市区；
- 方案 B：直接空载返回市区，重新寻找乘客。

方案 A 的优势是能够获得机场乘客订单，通常行驶距离和车费相对较高；缺点是需要在蓄车池中等待。

方案 B 不需要在机场排队，但司机需要承担返回市区的空驶成本，并且返回市区后仍需等待下一位乘客。

因此，本问的本质是：

\[
\boxed{\text{时变乘客需求条件下的二元收益决策问题}}
\]

司机决策的关键不是单纯比较两笔订单的车费，而是比较两种方案的单位时间预期净收益。

完整逻辑为：

\[
\text{航班到达信息}
\rightarrow
\text{出租车需求量}
\rightarrow
\text{预计等待时间}
\rightarrow
\text{两种方案单位时间净收益}
\rightarrow
\text{司机选择}
\]

---

## 四、模型假设

### 假设 1

出租车进入蓄车池后严格遵循先到先服务原则，不考虑插队、拒载和中途退出队列的情况。

### 假设 2

司机进入蓄车池后，后续到达的出租车均排在该司机之后，因此不影响该司机的等待时间。

### 假设 3

将一天划分为若干个等长时间段。在同一时间段内，乘客到达量和乘车区服务能力近似不变。

### 假设 4

航班落地后，乘客经过平均时间 \(\tau\) 到达出租车乘车区，不详细区分不同乘客下机和取行李时间的差异。

### 假设 5

同行乘客共乘一辆出租车，将实际乘客人数按照平均同行人数折算为出租车需求车辆数。

### 假设 6

司机以最大化单位时间预期净收益为决策目标，不考虑司机个人风险偏好和主观经验差异。

### 假设 7

在一次决策周期内，出租车运价、单位里程运营成本和过路费等保持不变。

## 六、模型建立

### 6.1 分时出租车需求估计

#### 6.1.1 单架航班产生的出租车需求

第 \(i\) 架航班的预计到达旅客人数为：

\[
S_i\rho_i
\]

其中选择出租车的旅客人数为：

\[
S_i\rho_i\theta_i
\]

考虑多名同行乘客可能共同乘坐一辆出租车，设平均每辆出租车搭载 \(g\) 名同行乘客，则第 \(i\) 架航班产生的出租车需求车辆数为：

\[
\boxed{
q_i=\frac{S_i\rho_i\theta_i}{g}
}
\]

这里的 \(q_i\) 表示预计需要多少辆出租车，而不是乘客总人数。

#### 6.1.2 计算各时间段的乘客需求

将一天划分为长度为 \(\Delta t\) 的时间段：

\[
[t_k,t_{k+1})
\]

假设第 \(i\) 架航班落地后经过平均时间 \(\tau\)，其乘客到达出租车乘车区。

因此，第 \(k\) 个时间段的新增出租车需求量为：

\[
\boxed{
D_k=
\sum_{i=1}^{m}
q_i
I\left(
t_k\leq a_i+\tau<t_{k+1}
\right)
}
\]

其中，\(I(\cdot)\) 为示性函数：

\[
I(\text{条件})=
\begin{cases}
1,&\text{条件成立},\\
0,&\text{条件不成立}.
\end{cases}
\]

代入 \(q_i\)，得到：

\[
\boxed{
D_k=
\sum_{i=1}^{m}
\frac{S_i\rho_i\theta_i}{g}
I\left(
t_k\leq a_i+\tau<t_{k+1}
\right)
}
\]

该式将航班到达数据转化为分时出租车需求量。

为了避免所有乘客集中在一个时间段内，实际编程时也可以将一架航班的需求按照一定比例分配到连续两到三个时间段中，例如：

\[
50\%,\quad 30\%,\quad 20\%
\]

但论文主模型中不必详细展开。

---

### 6.2 分时出租车服务量

乘客到达后，能够完成载客的出租车数量还会受到乘车区放行和上车能力的限制。

设第 \(k\) 个时间段内乘车区最多可以完成 \(C_k\) 辆出租车的乘客上车，则该时段实际能够消化的出租车数为：

\[
\boxed{
M_k=\min\{D_k,C_k\}
}
\]

其中：

- 当 \(D_k<C_k\) 时，实际载客量受乘客需求限制；
- 当 \(D_k\geq C_k\) 时，实际载客量受乘车区服务能力限制。

如果机场乘车区的服务能力明显高于乘客需求，也可以进一步近似为：

\[
M_k=D_k
\]

---

## 七、司机等待时间估计

假设目标司机在第 \(k_0\) 个时间段进入蓄车池，其前方已有 \(n_0\) 辆出租车。

目标司机在队列中的位置为：

\[
n_0+1
\]

从目标司机进入蓄车池开始，未来各时间段能够消化的车辆数依次为：

\[
M_{k_0},M_{k_0+1},M_{k_0+2},\ldots
\]

定义进入蓄车池后经过 \(j+1\) 个时间段，累计完成载客的出租车数为：

\[
H_j=
\sum_{l=0}^{j}M_{k_0+l}
\]

当累计完成载客车辆数第一次达到 \(n_0+1\) 时，目标司机获得乘客。

因此，令：

\[
\boxed{
j^*=
\min
\left\{
j:
\sum_{l=0}^{j}M_{k_0+l}
\geq n_0+1
\right\}
}
\]

为了提高等待时间计算精度，可以在最后一个时间段内进行线性插值。

设：

\[
H_{j^*-1}
=
\sum_{l=0}^{j^*-1}M_{k_0+l}
\]

并规定：

\[
H_{-1}=0
\]

则目标司机在最后一个时间段内尚需等待服务的车辆数为：

\[
n_0+1-H_{j^*-1}
\]

因此，目标司机预计等待时间为：

\[
\boxed{
T_w
=
j^*\Delta t
+
\frac{n_0+1-H_{j^*-1}}
{M_{k_0+j^*}}\Delta t
}
\]

该公式的含义是：

\[
\text{等待时间}
=
\text{完整经过的时间段}
+
\text{最后一个时间段内的部分时间}
\]

如果在研究时间范围内始终有：

\[
\sum M_k<n_0+1
\]

说明司机在较长时间内仍无法轮到，可以直接建议其空载返回市区。

## 八、两种方案的预期净收益

为了公平比较两种方案，将一次决策周期定义为：

> 从司机在机场作出决策开始，到完成下一笔载客订单结束。

### 8.1 方案 A：进入蓄车池排队

设：

- \(\bar F_A\)：机场订单平均车费；
- \(\bar D_A\)：机场订单平均行驶距离；
- \(\bar T_A\)：机场订单平均行驶时间；
- \(c_d\)：出租车单位里程运营成本；
- \(C_A\)：机场订单的过路费及其他固定成本；
- \(T_L\)：乘客上车及车辆驶离乘车区的平均时间。

机场订单的单次预期净利润为：

\[
\boxed{
\Pi_A
=
\bar F_A-c_d\bar D_A-C_A
}
\]

司机完成机场方案需要的总时间为：

\[
T_w+T_L+\bar T_A
\]

因此，机场排队方案的单位时间预期净收益为：

\[
\boxed{
r_A
=
\frac{\Pi_A}
{T_w+T_L+\bar T_A}
}
\]

即：

\[
\boxed{
r_A
=
\frac{
\bar F_A-c_d\bar D_A-C_A
}{
T_w+T_L+\bar T_A
}
}
\]

随着等待时间 \(T_w\) 增加，机场排队方案的单位时间收益不断下降。

---

### 8.2 方案 B：空载返回市区

设：

- \(D_0\)：机场到市区的空驶距离；
- \(T_0\)：机场到市区的空驶时间；
- \(\bar T_s\)：返回市区后平均寻客时间；
- \(\bar F_C\)：市区下一笔订单的平均车费；
- \(\bar D_C\)：市区订单平均行驶距离；
- \(\bar T_C\)：市区订单平均行驶时间；
- \(C_B\)：返回市区的过路费及其他固定成本。

司机返回市区并完成下一笔订单的预期净利润为：

\[
\boxed{
\Pi_B
=
\bar F_C
-c_d(D_0+\bar D_C)
-C_B
}
\]

其中，\(D_0\) 为空驶距离，没有乘客收入，但仍然产生运营成本。

返回市区方案的总时间为：

\[
T_0+\bar T_s+\bar T_C
\]

因此，返回市区方案的单位时间预期净收益为：

\[
\boxed{
r_B
=
\frac{\Pi_B}
{T_0+\bar T_s+\bar T_C}
}
\]

即：

\[
\boxed{
r_B
=
\frac{
\bar F_C-c_d(D_0+\bar D_C)-C_B
}{
T_0+\bar T_s+\bar T_C
}
}
\]

市区车费和寻客时间可以按照早高峰、平峰、晚高峰和夜间分别取值。

---

## 九、司机决策模型

司机的目标是选择单位时间预期净收益更高的方案。

因此，决策规则为：

\[
\boxed{
\begin{cases}
r_A\geq r_B,&\text{进入蓄车池排队},\\[2mm]
r_A<r_B,&\text{空载返回市区}.
\end{cases}
}
\]

定义收益差：

\[
\Delta r=r_A-r_B
\]

则也可以写为：

\[
\boxed{
\begin{cases}
\Delta r\geq0,&\text{进入蓄车池排队},\\
\Delta r<0,&\text{空载返回市区}.
\end{cases}
}
\]

---

## 十、临界等待时间

司机选择机场排队的条件为：

\[
r_A\geq r_B
\]

将机场排队方案收益率代入：

\[
\frac{\Pi_A}
{T_w+T_L+\bar T_A}
\geq r_B
\]

当 \(r_B>0\) 时，整理得到：

\[
T_w
\leq
\frac{\Pi_A}{r_B}
-T_L-\bar T_A
\]

定义临界等待时间为：

\[
\boxed{
T_w^*
=
\frac{\Pi_A}{r_B}
-T_L-\bar T_A
}
\]

于是得到更加直观的司机选择策略：

\[
\boxed{
\begin{cases}
T_w\leq T_w^*,&\text{进入蓄车池排队},\\[2mm]
T_w>T_w^*,&\text{空载返回市区}.
\end{cases}
}
\]

其中，\(T_w^*\) 表示司机能够接受的最长排队时间。

如果：

\[
T_w^*<0
\]

说明即使机场完全不需要排队，机场订单的单位时间净收益仍低于返回市区方案，此时应直接返回市区。

---

## 十一、临界排队车辆数

司机实际到达机场时，更容易观察到蓄车池中有多少辆出租车，而不是直接知道等待时间。

因此，需要将临界等待时间转化为临界排队车辆数。

计算从时刻 \(t_0\) 开始，在未来 \(T_w^*\) 时间内能够完成载客的出租车总数：

\[
G(t_0,T_w^*)
\]

如果 \(T_w^*=L\Delta t+\delta\)，其中：

\[
L=\left\lfloor\frac{T_w^*}{\Delta t}\right\rfloor
\]

且：

\[
0\leq\delta<\Delta t
\]

则：

\[
\boxed{
G(t_0,T_w^*)
=
\sum_{l=0}^{L-1}M_{k_0+l}
+
\frac{\delta}{\Delta t}M_{k_0+L}
}
\]

由于目标司机排在第 \(n_0+1\) 位，因此选择排队需要满足：

\[
n_0+1\leq G(t_0,T_w^*)
\]

所以临界排队车辆数为：

\[
\boxed{
N^*(t_0)
=
\left\lfloor
G(t_0,T_w^*)-1
\right\rfloor
}
\]

最终司机可以直接按照现场车辆数决策：

\[
\boxed{
\begin{cases}
n_0\leq N^*(t_0),
&\text{进入蓄车池排队},\\[2mm]
n_0>N^*(t_0),
&\text{空载返回市区}.
\end{cases}
}
\]

由于未来航班数量和市区收入会随时间变化，因此：

\[
N^*(t_0)
\]

是一个随时段变化的动态阈值，而不是全天固定的车辆数。

---

## 十二、模型求解步骤

### 步骤一：划分时间段

将一天划分为长度为：

\[
\Delta t=10\text{分钟}
\]

的时间段。

### 步骤二：计算单架航班出租车需求

根据：

\[
q_i=\frac{S_i\rho_i\theta_i}{g}
\]

计算每架航班预计产生的出租车需求车辆数。

### 步骤三：生成分时乘客需求

将航班落地时间向后平移平均延迟时间 \(\tau\)，计算各时间段的出租车需求：

\[
D_k
\]

### 步骤四：计算分时服务量

根据乘客需求和乘车区最大服务能力，计算：

\[
M_k=\min\{D_k,C_k\}
\]

### 步骤五：估计司机等待时间

给定司机到达时刻 \(t_0\) 和前方车辆数 \(n_0\)，依次累加未来各时段的 \(M_k\)，直到累计服务量达到：

\[
n_0+1
\]

由此得到预计等待时间 \(T_w\)。

### 步骤六：计算机场排队方案收益

计算：

\[
\Pi_A
=
\bar F_A-c_d\bar D_A-C_A
\]

以及：

\[
r_A
=
\frac{\Pi_A}
{T_w+T_L+\bar T_A}
\]

### 步骤七：计算返回市区方案收益

计算：

\[
\Pi_B
=
\bar F_C-c_d(D_0+\bar D_C)-C_B
\]

以及：

\[
r_B
=
\frac{\Pi_B}
{T_0+\bar T_s+\bar T_C}
\]

### 步骤八：求临界阈值

计算临界等待时间：

\[
T_w^*
=
\frac{\Pi_A}{r_B}
-T_L-\bar T_A
\]

再根据未来 \(T_w^*\) 时间内能够消化的车辆数，计算：

\[
N^*(t_0)
\]

### 步骤九：输出司机策略

若：

\[
T_w\leq T_w^*
\]

或者等价地：

\[
n_0\leq N^*(t_0)
\]

则进入蓄车池排队；否则空载返回市区。

---

## 十三、不确定因素的简化处理

本问不再使用蒙特卡洛模拟，只对三个关键参数进行敏感性分析：

\[
\theta,\qquad \bar T_s,\qquad \bar F_A
\]

可以分别令它们在基准值上下变化：

\[
-10\%,-5\%,0,5\%,10\%
\]

观察以下结果是否发生明显变化：

\[
T_w^*,\qquad N^*(t_0),\qquad \Delta r
\]

如果某个参数略微变化就导致司机选择反转，说明模型对该参数较为敏感，实际应用时需要重点准确估计。

---

## 十四、模型应输出的结果

精简模型最终只需要输出以下内容：

1. 各时间段出租车乘客需求量 \(D_k\)；
2. 各时间段能够消化的出租车数 \(M_k\)；
3. 目标司机预计等待时间 \(T_w\)；
4. 机场排队方案单位时间净收益 \(r_A\)；
5. 返回市区方案单位时间净收益 \(r_B\)；
6. 临界等待时间 \(T_w^*\)；
7. 临界排队车辆数 \(N^*(t)\)；
8. 最终建议策略。

论文中建议保留三张图：

- 出租车乘客需求随时间变化图；
- 排队车辆数与预计等待时间关系图；

## 十五、精简模型的优势

| 原模型内容 | 精简后的处理 |
|---|---|
| 出租车和乘客双队列递推 | 只计算未来乘客能够消化的车辆数 |
| 后续进入蓄车池的车辆 | 先到先服务下不影响目标司机，舍去 |
| 乘客下机时间概率分布 | 使用平均延迟时间 |
| 等待时间成本 | 通过单位时间净收益自动体现 |
| 蒙特卡洛模拟 | 改为简单敏感性分析 |
| 大量随机参数 | 使用分时平均参数 |

尽管模型得到简化，但仍保留了题目的三个关键要求：

- 机场乘客数量随时间变化；
- 司机排队等待时间；
- 两种选择的收益比较。

因此，它比简单的固定排队时间模型更有针对性，又比完整双队列随机模型更容易写进论文和进行编程求解。

## 十六、可直接写入论文的模型总结

针对出租车司机送客到达机场后在“进入蓄车池排队”和“空载返回市区”之间的选择问题，本文建立基于分时乘客需求估计的等待时间—净收益阈值决策模型。

首先，将一天划分为若干等长时间段，根据各到达航班的可载客人数、客座率、乘客出租车选择比例及平均同行人数，估计每架航班产生的出租车需求车辆数；考虑乘客从航班落地到出租车乘车区存在一定时间延迟，将航班需求分配至对应的后续时间段，得到分时出租车需求序列。

其次，综合乘客需求与机场乘车区服务能力，计算各时间段能够完成载客的出租车数量，并依据先到先服务原则，累计未来各时段的服务车辆数，估计目标司机的排队等待时间。

最后，分别建立机场排队方案和空载返回市区方案的单位时间预期净收益函数，以两种方案收益相等为临界条件，求得临界等待时间和临界排队车辆数。

当司机的预计等待时间不超过临界等待时间，或其前方车辆数不超过临界排队车辆数时，选择进入蓄车池排队；否则选择空载返回市区。

最终决策规则为：

\[
\boxed{
\begin{cases}
T_w\leq T_w^*,&\text{进入蓄车池排队},\\[2mm]
T_w>T_w^*,&\text{空载返回市区}.
\end{cases}
}
\]

等价地：

\[
\boxed{
\begin{cases}
n_0\leq N^*(t_0),&\text{进入蓄车池排队},\\[2mm]
n_0>N^*(t_0),&\text{空载返回市区}.
\end{cases}
}
\]

该精简模型已经能够作为第一问的完整模型，后续第二问只需代入具体机场的航班、距离、运价、成本和市区寻客数据即可。
