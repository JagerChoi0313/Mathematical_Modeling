# 问题一：基于时变排队等待时间估计的预期净收益阈值决策模型

## 1 问题分析

出租车司机送客到机场后，需要在以下两种方案中作出选择：

- 方案 A：进入机场蓄车池排队，等待载客返回市区；
- 方案 B：不进入蓄车池，直接空载返回市区寻找乘客。

司机进入蓄车池后的等待时间，不仅取决于当前蓄车池内已有的出租车数量，还受到未来一段时间内到达航班数量、航班载客量、乘客选择出租车的比例以及乘车区服务能力等因素影响。

由于机场航班并不是均匀到达的，出租车乘客的需求量会随时间发生明显变化。因此，该问题不能简单地用固定到达率的普通排队模型处理，而应建立随时间变化的动态排队模型。

本问的本质是：

\[
\boxed{\text{时变供需环境下的二元收益决策问题}}
\]

完整的建模逻辑为：

\[
\text{航班到达信息}
\rightarrow
\text{出租车乘客需求预测}
\rightarrow
\text{出租车与乘客队列变化}
\rightarrow
\text{司机等待时间估计}
\rightarrow
\text{两种方案收益比较}
\rightarrow
\text{司机选择策略}
\]

如果只建立收益模型，就无法合理估计司机在机场的排队等待时间；如果只建立排队模型，又不能直接判断司机应该排队还是返回市区。

因此，本文建立基于时变排队等待时间估计的预期净收益阈值决策模型。首先根据航班到达信息预测不同时段的出租车乘客需求；其次建立出租车队列和乘客队列的动态递推模型，估计目标司机的等待时间；最后分别计算机场排队方案和空载返回市区方案的单位时间预期净收益，通过收益比较得到临界等待时间和临界排队车辆数。

---

## 2 模型假设

为便于模型建立和求解，作出以下假设。

### 假设 1

出租车进入机场蓄车池后，严格按照先到先服务原则排队，不考虑插队、拒载及司机中途退出队列的情况。

### 假设 2

将具有共同目的地或共同乘车意愿的同行乘客视为一个乘客组，每个乘客组原则上需要一辆出租车。

### 假设 3

将一天划分为若干个长度相等的短时间段。在同一时间段内，乘客到达率、出租车到达率和乘车区服务能力近似保持不变，但允许这些参数在不同时段之间发生变化。

### 假设 4

航班客座率、到达旅客比例、乘客选择出租车的比例，以及乘客从航班落地到进入出租车乘车区的时间分布，可以根据同类日期和同类时段的历史数据进行估计。

### 假设 5

出租车司机以最大化单位时间预期净收益为主要决策目标，不考虑不同司机在风险偏好、疲劳程度和主观经验方面的差异。

### 假设 6

在单次决策周期内，出租车运价、单位里程运营成本、油价或电价及过路费等参数保持不变。

### 假设 7

机场乘车区的服务能力有限，单位时间内完成乘客上车的出租车数量不能超过机场的最大放行和上车能力。

## 4 出租车乘客需求预测模型

### 4.1 单架航班产生的出租车需求

第 \(i\) 架航班预计到达旅客人数为：

\[
S_i\rho_i\eta_i
\]

其中：

- \(S_i\) 为第 \(i\) 架航班的可载客人数；
- \(\rho_i\) 为航班客座率；
- \(\eta_i\) 为实际进入机场到达区的旅客比例。

选择出租车的旅客人数为：

\[
S_i\rho_i\eta_i\theta_i
\]

由于多名同行旅客可能共同乘坐一辆出租车，设第 \(i\) 架航班乘客的平均同行人数为 \(g_i\)，则该航班预计产生的出租车需求组数为：

\[
\boxed{
q_i=\frac{S_i\rho_i\eta_i\theta_i}{g_i}
}
\]

在实际计算中，\(q_i\) 可以保留为期望值，也可以根据需要进行取整。

---

### 4.2 乘客到达乘车区的时间延迟

航班落地后，乘客还需要经历下机、步行、提取行李以及办理入境手续等过程，因此乘客不会在航班落地后立即到达出租车乘车区。

设随机变量 \(L_i\) 表示第 \(i\) 架航班乘客从航班落地到进入出租车乘车区所需要的时间，其概率密度函数为：

\[
f_i(l)
\]

设第 \(i\) 架航班的落地时刻为 \(a_i\)，第 \(k\) 个时间段为：

\[
[t_k,t_{k+1})
\]

则第 \(i\) 架航班乘客在第 \(k\) 个时间段到达乘车区的比例为：

\[
p_{ik}
=
P(t_k-a_i\leq L_i<t_{k+1}-a_i)
\]

即：

\[
p_{ik}
=
\int_{t_k-a_i}^{t_{k+1}-a_i}f_i(l)\,dl
\]

并满足：

\[
\sum_k p_{ik}=1
\]

因此，第 \(k\) 个时间段新增的出租车需求组数为：

\[
\boxed{
A_k=\sum_{i=1}^{m}q_ip_{ik}
}
\]

将 \(q_i\) 代入，得到：

\[
\boxed{
A_k
=
\sum_{i=1}^{m}
\frac{S_i\rho_i\eta_i\theta_i}{g_i}p_{ik}
}
\]

该式将机场航班到达信息转化为随时间变化的出租车乘客需求序列。

---

### 4.3 缺少详细乘客到达数据时的处理

如果没有乘客从航班落地到出租车乘车区的详细时间数据，可以假设乘客释放时间服从正态分布：

\[
L_i\sim N(\mu_L,\sigma_L^2)
\]

其中：

- \(\mu_L\) 为乘客从航班落地到乘车区的平均时间；
- \(\sigma_L\) 为不同乘客下机和提取行李时间的离散程度。

此时：

\[
p_{ik}
=
\Phi\left(
\frac{t_{k+1}-a_i-\mu_L}{\sigma_L}
\right)
-
\Phi\left(
\frac{t_k-a_i-\mu_L}{\sigma_L}
\right)
\]

其中，\(\Phi(\cdot)\) 为标准正态分布函数。

若实际数据呈现明显右偏，可以采用对数正态分布代替正态分布。

---

## 5 机场时变双队列模型

机场出租车载客过程同时存在两个队列：

1. 蓄车池中的出租车队列；
2. 乘车区中的乘客队列。

只有当出租车和乘客同时存在，并且机场乘车区仍有服务能力时，才能完成一次乘客与出租车的匹配。

---

### 5.1 乘车区最大服务能力

设第 \(k\) 个时间段内，乘车区共有 \(s_k\) 个有效上车点，每个上车点完成一次乘客上车平均需要 \(\tau_k\) 时间，则该时间段的理论最大服务能力为：

\[
\frac{s_k\Delta t}{\tau_k}
\]

考虑车辆进出、人员组织和安全间隔造成的效率损失，引入服务效率系数 \(\xi_k\)，其中：

\[
0<\xi_k\leq 1
\]

则第 \(k\) 个时间段乘车区的最大服务车辆数为：

\[
\boxed{
C_k
=
\xi_k\frac{s_k\Delta t}{\tau_k}
}
\]

---

### 5.2 实际完成载客的出租车数量

第 \(k\) 个时间段能够提供服务的出租车总数为：

\[
Q_k^T+B_k
\]

能够乘坐出租车的乘客组总数为：

\[
Q_k^P+A_k
\]

因此，第 \(k\) 个时间段实际完成载客的出租车数量为：

\[
\boxed{
X_k
=
\min
\left\{
Q_k^T+B_k,\,
Q_k^P+A_k,\,
C_k
\right\}
}
\]

该式表明，实际完成载客的数量同时受到以下三个因素限制：

- 当前可用出租车数量；
- 当前可用乘客组数量；
- 机场乘车区最大服务能力。

---

### 5.3 出租车队列递推方程

第 \(k\) 个时间段结束后，蓄车池内剩余的出租车数量为：

\[
\boxed{
Q_{k+1}^T
=
Q_k^T+B_k-X_k
}
\]

即：

\[
\text{下一时段出租车数}
=
\text{当前出租车数}
+
\text{新进入出租车数}
-
\text{完成载客出租车数}
\]

---

### 5.4 乘客队列递推方程

第 \(k\) 个时间段结束后，仍在乘车区等待的乘客组数量为：

\[
\boxed{
Q_{k+1}^P
=
Q_k^P+A_k-X_k
}
\]

两个队列均满足非负约束：

\[
Q_k^T\geq 0
\]

\[
Q_k^P\geq 0
\]

---

## 6 目标司机等待时间估计

假设目标司机在第 \(k_0\) 个时间段开始时进入机场蓄车池。

司机进入蓄车池时，其前方已有 \(n_0\) 辆出租车，因此目标司机在队列中的位置为：

\[
R_0=n_0+1
\]

由于出租车按照先到先服务原则排队，只有在前方 \(n_0\) 辆出租车全部完成载客后，目标司机才能进入乘车区。

定义从第 \(k_0\) 个时间段开始，到第 \(j\) 个时间段结束时，累计完成载客的出租车数量为：

\[
H_j=\sum_{k=k_0}^{j}X_k
\]

目标司机完成排队并获得乘客的时间段为：

\[
\boxed{
k^*
=
\min
\left\{
j:H_j\geq n_0+1
\right\}
}
\]

若直接采用离散时间估计，则目标司机的等待时间为：

\[
T_w=(k^*-k_0+1)\Delta t
\]

为了减小时间离散造成的误差，可以在最后一个时间段内进行线性插值。

设：

\[
H_{k^*-1}
=
\sum_{k=k_0}^{k^*-1}X_k
\]

则进入第 \(k^*\) 个时间段时，目标司机前面尚未完成服务的车辆数为：

\[
n_0+1-H_{k^*-1}
\]

若假设第 \(k^*\) 个时间段内的服务均匀完成，则目标司机在该时间段内需要等待的比例为：

\[
\frac{n_0+1-H_{k^*-1}}{X_{k^*}}
\]

因此，目标司机更加精确的等待时间为：

\[
\boxed{
T_w
=
(k^*-k_0)\Delta t
+
\frac{n_0+1-H_{k^*-1}}
{X_{k^*}}\Delta t
}
\]

规定：

\[
H_{k_0-1}=0
\]

如果在设定的研究时间范围内始终满足：

\[
H_j<n_0+1
\]

说明目标司机在该研究时间范围内无法完成载客，可以将其等待时间视为无穷大，或者直接建议司机空载返回市区。

## 7 两种方案的预期净收益模型

机场排队方案和返回市区方案所需要的时间不同。

如果只比较一笔订单的车费，可能出现机场订单车费较高，但司机排队时间过长，导致单位时间收入较低的情况。

因此，本文采用单位时间预期净收益作为两种方案的统一比较指标。

---

### 7.1 方案 A：进入蓄车池排队

设机场乘客目的地的随机行驶距离为 \(D_A\)，行驶时间为 \(T_A\)，对应车费为 \(F_A\)。

机场订单的预期净利润为：

\[
\Pi_A
=
E(F_A)
-
c_dE(D_A)
-
C_A^{\mathrm{fix}}
\]

其中：

- \(c_d\) 为出租车单位里程运营成本；
- \(C_A^{\mathrm{fix}}\) 为机场订单的过路费及其他固定费用。

如果需要考虑堵车、怠速等产生的时间运营成本，可以引入单位时间运营成本 \(c_t\)，此时机场订单预期净利润为：

\[
\boxed{
\Pi_A
=
E(F_A)
-
c_dE(D_A)
-
c_tE(T_A)
-
C_A^{\mathrm{fix}}
}
\]

机场排队方案的总时间包括：

- 排队等待时间 \(T_w\)；
- 乘客上车时间 \(T_L\)；
- 载客行驶时间 \(E(T_A)\)。

因此，机场排队方案的单位时间预期净收益为：

\[
\boxed{
r_A
=
\frac{\Pi_A}
{T_w+T_L+E(T_A)}
}
\]

即：

\[
\boxed{
r_A
=
\frac{
E(F_A)-c_dE(D_A)-c_tE(T_A)-C_A^{\mathrm{fix}}
}{
T_w+T_L+E(T_A)
}
}
\]

---

### 7.2 方案 B：空载返回市区

司机空载返回市区需要承担以下成本：

- 从机场到市区的空驶里程成本；
- 空驶过程中的时间运营成本；
- 返回市区后的寻客时间；
- 空驶产生的过路费及其他固定费用。

设：

- \(D_0\) 为机场至主要市区的空驶距离；
- \(T_0\) 为机场至主要市区的空驶时间；
- \(T_s\) 为返回市区后的寻客时间；
- \(D_C\) 为市区订单的平均行驶距离；
- \(T_C\) 为市区订单的平均行驶时间；
- \(F_C\) 为市区订单的车费。

空载返回市区并完成下一笔市区订单的预期净利润为：

\[
\boxed{
\Pi_B
=
E(F_C)
-
c_d\left[D_0+E(D_C)\right]
-
c_t\left[T_0+E(T_C)\right]
-
C_B^{\mathrm{fix}}
}
\]

其中，\(C_B^{\mathrm{fix}}\) 为返回市区时的过路费及其他固定成本。

返回市区方案的总时间为：

\[
T_0+E(T_s)+E(T_C)
\]

因此，该方案的单位时间预期净收益为：

\[
\boxed{
r_B
=
\frac{\Pi_B}
{T_0+E(T_s)+E(T_C)}
}
\]

即：

\[
\boxed{
r_B
=
\frac{
E(F_C)
-c_d[D_0+E(D_C)]
-c_t[T_0+E(T_C)]
-C_B^{\mathrm{fix}}
}{
T_0+E(T_s)+E(T_C)
}
}
\]

其中，\(E(F_C)\)、\(E(T_s)\)、\(E(D_C)\) 和 \(E(T_C)\) 应根据市区早高峰、平峰、晚高峰和夜间等不同时段分别估计。

## 8 司机选择决策模型

定义二元决策变量：

\[
x=
\begin{cases}
1,&\text{进入机场蓄车池排队}\\
0,&\text{空载返回市区}
\end{cases}
\]

司机的决策目标是最大化单位时间预期净收益：

\[
\boxed{
\max_{x\in\{0,1\}}
Z=xr_A+(1-x)r_B
}
\]

因此，最优决策为：

\[
\boxed{
x^*=
\begin{cases}
1,&r_A\geq r_B\\
0,&r_A<r_B
\end{cases}
}
\]

即：

\[
\boxed{
\begin{cases}
r_A\geq r_B,&\text{选择进入机场蓄车池排队}\\
r_A<r_B,&\text{选择空载返回市区}
\end{cases}
}
\]

---

## 9 临界等待时间模型

司机选择机场排队的条件为：

\[
r_A\geq r_B
\]

将机场排队方案的单位时间预期净收益代入，得到：

\[
\frac{\Pi_A}
{T_w+T_L+E(T_A)}
\geq r_B
\]

当 \(r_B>0\) 时，整理得到：

\[
T_w+T_L+E(T_A)
\leq
\frac{\Pi_A}{r_B}
\]

进一步得到：

\[
T_w
\leq
\frac{\Pi_A}{r_B}
-
T_L
-
E(T_A)
\]

定义司机可以接受的最大排队等待时间为：

\[
\boxed{
T_w^*
=
\frac{\Pi_A}{r_B}
-
T_L
-
E(T_A)
}
\]

由此得到基于临界等待时间的司机决策规则：

\[
\boxed{
\begin{cases}
T_w\leq T_w^*,&\text{进入机场蓄车池排队}\\
T_w>T_w^*,&\text{空载返回市区}
\end{cases}
}
\]

该阈值的经济含义为：

当机场排队所需要的时间没有超过司机能够接受的最大等待时间时，机场排队方案的单位时间净收益不低于返回市区方案，司机应选择进入蓄车池；反之，司机应直接空载返回市区。

---

### 9.1 临界等待时间的特殊情况

#### 情况一：\(T_w^*<0\)

如果：

\[
T_w^*<0
\]

说明即使司机进入机场后完全不需要排队，机场订单的单位时间净收益仍然低于返回市区方案。

此时司机应直接空载返回市区。

#### 情况二：\(r_B\leq 0\)

如果：

\[
r_B\leq 0
\]

说明空载返回市区的单位时间预期净收益非正。

此时不能直接使用除法形式计算 \(T_w^*\)，而应直接比较：

\[
r_A
\]

与：

\[
r_B
\]

通常情况下，如果机场排队方案能够获得正的单位时间净收益，则司机应优先选择机场排队。

---

## 10 临界排队车辆数模型

在实际决策中，司机更容易观察蓄车池中的车辆数量，而不容易直接判断自己的排队等待时间。

因此，需要将临界等待时间进一步转化为临界排队车辆数。

设司机在时刻 \(t_0\) 进入蓄车池时，前方已有 \(n\) 辆出租车。

利用时变排队模型，可以得到司机等待时间函数：

\[
T_w=T_w(n,t_0)
\]

定义时刻 \(t_0\) 的临界排队车辆数为：

\[
\boxed{
N^*(t_0)
=
\max
\left\{
n:T_w(n,t_0)\leq T_w^*
\right\}
}
\]

因此，基于排队车辆数的司机决策规则为：

\[
\boxed{
\begin{cases}
Q_{k_0}^T\leq N^*(t_0),
&\text{进入机场蓄车池排队}\\
Q_{k_0}^T>N^*(t_0),
&\text{空载返回市区}
\end{cases}
}
\]

由于航班数量、乘客需求和市区收益均随时间变化，所以：

\[
N^*(t_0)
\]

不是一个固定常数，而是随司机到达机场的时刻变化的动态阈值。

---

### 10.1 临界车辆数的近似计算

如果未来较短时间内乘客到达率基本稳定，设该时段平均每小时能够消化的出租车数量为：

\[
\bar{\mu}(t_0)
\]

则司机的等待时间可以近似表示为：

\[
T_w(n,t_0)
\approx
\frac{n+1}{\bar{\mu}(t_0)}
\]

将其代入临界等待条件：

\[
\frac{n+1}{\bar{\mu}(t_0)}
\leq T_w^*
\]

得到：

\[
n
\leq
\bar{\mu}(t_0)T_w^*-1
\]

因此，临界排队车辆数可以近似表示为：

\[
\boxed{
N^*(t_0)
\approx
\left\lfloor
\bar{\mu}(t_0)T_w^*-1
\right\rfloor
}
\]

该近似公式可以用于快速估计。

在正式求解中，应优先利用时变双队列递推模型计算准确的临界车辆数。

---

## 11 不确定因素处理

机场运行中存在多种不确定因素，包括：

- 航班延误；
- 航班实际客座率变化；
- 乘客选择出租车的比例变化；
- 乘客提取行李时间变化；
- 市区道路拥堵；
- 市区寻客时间变化；
- 机场乘客目的地距离变化。

可以将以下参数设置为随机变量：

\[
\rho_i,\quad
\theta_i,\quad
L_i,\quad
T_s,\quad
D_A,\quad
T_A
\]

并采用蒙特卡洛模拟分析不确定因素对司机决策结果的影响。

---

### 11.1 蒙特卡洛模拟过程

设共进行 \(M\) 次随机模拟。

在第 \(m\) 次模拟中，执行以下步骤：

1. 随机生成各航班的延误时间；
2. 随机生成航班客座率和乘客出租车选择比例；
3. 计算第 \(m\) 次模拟下各时间段的乘客需求 \(A_k^{(m)}\)；
4. 递推计算目标司机的等待时间 \(T_w^{(m)}\)；
5. 计算两种方案的单位时间预期净收益：

\[
r_A^{(m)}
\]

和：

\[
r_B^{(m)}
\]

6. 计算两种方案的收益差：

\[
\Delta r^{(m)}
=
r_A^{(m)}-r_B^{(m)}
\]

机场排队方案的平均收益优势为：

\[
\overline{\Delta r}
=
\frac{1}{M}
\sum_{m=1}^{M}
\Delta r^{(m)}
\]

机场排队方案优于返回市区方案的概率为：

\[
\boxed{
P_A
=
\frac{1}{M}
\sum_{m=1}^{M}
I\left(
r_A^{(m)}\geq r_B^{(m)}
\right)
}
\]

其中，\(I(\cdot)\) 为示性函数。当括号内条件成立时取 1，否则取 0。

---

### 11.2 稳健决策规则

设司机要求机场排队方案优于返回市区方案的概率至少达到 \(\alpha\)，例如：

\[
\alpha=0.7
\]

则稳健决策规则为：

\[
\boxed{
\begin{cases}
P_A\geq\alpha,
&\text{建议进入机场蓄车池}\\
P_A\leq1-\alpha,
&\text{建议空载返回市区}\\
1-\alpha<P_A<\alpha,
&\text{判定为决策模糊区}
\end{cases}
}
\]

对于处于决策模糊区的司机，可以根据最新航班信息和蓄车池车辆数量重新进行判断。

蒙特卡洛模拟主要用于检验模型的稳定性，主模型仍采用临界等待时间和临界车辆数进行决策。

---

## 12 模型求解步骤

### 步骤 1：划分时间段

将一天划分为长度为 \(\Delta t\) 的若干时间段。

建议取：

\[
\Delta t=5\text{分钟}
\]

或：

\[
\Delta t=10\text{分钟}
\]

时间段过长会掩盖航班集中到达造成的需求波动，时间段过短则会增加数据要求和计算量。

---

### 步骤 2：计算单架航班的出租车需求

根据：

\[
q_i
=
\frac{S_i\rho_i\eta_i\theta_i}{g_i}
\]

计算每架到达航班预计产生的出租车需求组数。

---

### 步骤 3：生成分时乘客需求序列

根据乘客从航班落地到进入乘车区的时间分布，计算：

\[
p_{ik}
\]

进一步得到：

\[
A_k
=
\sum_iq_ip_{ik}
\]

由此形成全天出租车乘客需求时间序列。

---

### 步骤 4：计算出租车和乘客队列状态

给定初始队列：

\[
Q_1^T
\]

和：

\[
Q_1^P
\]

对每个时间段依次计算：

\[
X_k
=
\min
\left\{
Q_k^T+B_k,\,
Q_k^P+A_k,\,
C_k
\right\}
\]

随后更新出租车队列：

\[
Q_{k+1}^T
=
Q_k^T+B_k-X_k
\]

更新乘客队列：

\[
Q_{k+1}^P
=
Q_k^P+A_k-X_k
\]

---

### 步骤 5：估计目标司机等待时间

给定目标司机进入机场蓄车池的时刻 \(t_0\) 及前方车辆数 \(n_0\)，累计计算：

\[
H_j
=
\sum_{k=k_0}^{j}X_k
\]

确定：

\[
k^*
=
\min
\left\{
j:H_j\geq n_0+1
\right\}
\]

再通过线性插值计算司机的预计等待时间 \(T_w\)。

---

### 步骤 6：计算两种方案的预期净收益

计算机场排队方案：

\[
\Pi_A
\]

和：

\[
r_A
\]

计算空载返回市区方案：

\[
\Pi_B
\]

和：

\[
r_B
\]

---

### 步骤 7：计算临界等待时间

根据：

\[
T_w^*
=
\frac{\Pi_A}{r_B}
-
T_L
-
E(T_A)
\]

得到司机可以接受的最大排队等待时间。

---

### 步骤 8：计算临界排队车辆数

从：

\[
n=0
\]

开始，逐渐增加司机前方的排队车辆数。

对每一个 \(n\)，通过时变排队模型计算：

\[
T_w(n,t_0)
\]

找到满足：

\[
T_w(n,t_0)\leq T_w^*
\]

的最大 \(n\)，将其作为该时刻的临界排队车辆数：

\[
N^*(t_0)
\]

---

### 步骤 9：输出司机选择策略

根据司机到达机场时观察到的蓄车池车辆数 \(Q_{k_0}^T\)，判断：

\[
Q_{k_0}^T\leq N^*(t_0)
\]

是否成立。

若成立，则建议司机进入机场蓄车池排队；否则建议司机直接空载返回市区。

---

## 13 模型求解流程

完整的模型求解流程为：

\[
\boxed{
\begin{aligned}
&\text{输入航班、车辆、运价及成本数据}\\
&\downarrow\\
&\text{估计每架航班产生的出租车需求}\\
&\downarrow\\
&\text{考虑下机延迟，生成分时乘客需求序列}\\
&\downarrow\\
&\text{递推出租车队列和乘客队列}\\
&\downarrow\\
&\text{估计目标司机的排队等待时间}\\
&\downarrow\\
&\text{计算机场排队方案的单位时间净收益}\\
&\downarrow\\
&\text{计算返回市区方案的单位时间净收益}\\
&\downarrow\\
&\text{求解临界等待时间和临界车辆数}\\
&\downarrow\\
&\text{输出出租车司机的选择策略}
\end{aligned}
}
\]

---

N^*(t)

## 16 模型合理性分析

第一，模型没有只根据当前蓄车池车辆数量作出判断，而是进一步考虑了未来航班到达带来的乘客需求变化。

第二，模型同时建立出租车队列和乘客队列，能够反映“出租车等待乘客”和“乘客等待出租车”两种不同的运行状态。

第三，模型将机场载客收入、行驶成本、过路费、空驶成本以及市区寻客时间等因素统一转化为单位时间预期净收益，保证两种方案具有可比性。

第四，模型最终输出临界等待时间和临界排队车辆数，具有明确的经济意义，也便于出租车司机根据现场信息直接作出选择。

第五，通过蒙特卡洛模拟和敏感性分析，可以检验航班延误、乘客出租车选择率及市区寻客时间变化对司机决策结果的影响。

## 17 模型总结

针对机场航班分布不均、乘客进入出租车乘车区存在时间延迟以及蓄车池车辆数量动态变化的问题，本文建立基于时变排队等待时间估计的预期净收益阈值决策模型。

首先，根据航班可载客人数、客座率、到达旅客比例、出租车分担率及平均同行人数，估计每架航班产生的出租车需求组数。

随后，引入乘客从航班落地到进入出租车乘车区的时间分布，将各航班产生的出租车需求分配到不同时间段，得到时变乘客需求序列。

其次，以蓄车池出租车和乘车区乘客作为两个相互匹配的队列，在考虑乘车区最大服务能力的基础上，建立出租车队列和乘客队列的动态状态递推方程，并根据目标司机前方车辆数及累计完成载客车辆数估计司机的排队等待时间。

最后，综合考虑机场订单车费、行驶成本、过路费、空驶费用及市区寻客时间，分别建立机场排队方案和空载返回市区方案的单位时间预期净收益函数。

以两种方案的单位时间预期净收益相等为临界条件，求得临界等待时间：

\[
\boxed{
T_w^*
=
\frac{\Pi_A}{r_B}
-
T_L
-
E(T_A)
}
\]

进一步利用时变排队模型，将临界等待时间转化为临界排队车辆数：

\[
\boxed{
N^*(t_0)
=
\max
\left\{
n:T_w(n,t_0)\leq T_w^*
\right\}
}
\]

最终的司机选择策略为：

\[
\boxed{
\begin{cases}
T_w\leq T_w^*,&\text{选择进入机场蓄车池排队}\\
T_w>T_w^*,&\text{选择空载返回市区}
\end{cases}
}
\]

等价地，也可以根据司机现场观察到的排队车辆数表示为：

\[
\boxed{
\begin{cases}
Q^T(t_0)\leq N^*(t_0),
&\text{选择进入机场蓄车池排队}\\
Q^T(t_0)>N^*(t_0),
&\text{选择空载返回市区}
\end{cases}
}
\]

临界等待时间和临界排队车辆数是同一决策规则的两种表达形式，实际使用时任选其中一种进行判断即可。
